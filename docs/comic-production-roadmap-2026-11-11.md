# 漫剧生产线后续计划

> 状态：仅规划和文档记录，不进入当前开发迭代。  
> 当前平台继续以 AI 短剧的剧本、分镜、镜头视频、时间线和交付为中心。

## 1. 为什么不现在引入

漫剧不是给短剧镜头增加一个“漫画滤镜”，而是一条不同的生产链：

- 短剧的核心单位是镜头、时间线和音频。
- 漫剧的核心单位是分格、页/条漫节奏、气泡、旁白、拟声字和阅读顺序。
- 两者可以共享故事、人物 Canon、原文和视觉锚点，但不能假设共享同一套产物模型。

在短剧成片质量、成本数据和真实生产验收尚未稳定前，同时引入漫剧会扩大质量风险、交付格式复杂度和 UI 操作负担。

## 2. 未来产品定位

漫剧模式应作为独立的“内容形态”扩展，而不是替换短剧：

- 复用：故事 Brief、人物关系、三幕、分集、场景、角色/地点视觉锚点、版本、额度、审片和项目权限。
- 独立：漫剧分格、页/条漫排版、气泡与字效、阅读顺序、页级渲染和漫画包导出。
- 不共享：短剧时间线成片不再直接充当漫剧产物；漫剧页也不再塞进镜头视频时间线。

## 3. 建议分阶段

### P0 静态漫剧最小闭环

- 从已有分集/分镜派生漫画分格草案，不重新生成故事。
- 提供分格顺序、分页、留白、裁切和每格画面采用。
- 支持旁白框、普通对白气泡、拟声字和基础字体。
- 支持单页预览、整集连续阅读预览。
- 导出单页 PNG、整集 PDF/ZIP，并写入 AI 来源说明和版本 manifest。
- 验收一条 12～24 格、3～5 分钟的静态漫剧样片。

### P1 条漫与连续生产

- 支持竖向条漫版式、分段发布和移动阅读预览。
- 增加角色多角度、表情、服装状态和场景空间连续性检查。
- 支持分格级生成、重生成、局部返修和影响范围预览。
- 增加气泡避让、文字溢出、阅读顺序和安全区自动检查。
- 支持按集批量生产、断点恢复和版本对比。

### P2 动态漫剧

- 在静态漫剧闭环稳定后，再增加镜头推移、局部动效、对白和 TTS。
- 动态漫剧仍需使用独立产物类型，不把静态漫剧页直接转换成短剧时间线。
- 评估是否接入唇形、表情驱动和角色动作，不提前承诺当前模型能力。

## 4. 技术边界

- 新产物类型建议为 `comicPages` / `comicLayouts`，不混用 `shots` 或 `timeline`。
- 页面渲染优先使用可复现的 HTML/SVG/Canvas 排版层，生成图片只作为分格素材。
- 漫剧模式必须使用 feature flag，未开启时不修改现有首页、创作、画布和交付中心结构。
- 所有漫剧产物继续使用项目 owner、快照、版本、额度、任务和备份机制。
- 外部漫画素材回流必须经过授权、哈希和来源记录。

## 5. 验收指标

- 12～24 格静态漫剧能否在 30 分钟内完成第一版。
- 气泡遮挡、文字溢出和阅读顺序错误率。
- 角色跨格一致性通过率。
- 每页/每格真实生成成本与返修成本。
- 用户是否能从已有短剧项目无损派生漫剧，而不复制两套故事事实。

## 6. 暂不做

- 不在当前短剧工作台塞入漫画分格编辑器。
- 不做通用插画工具或社区素材市场。
- 不做完整专业漫画 NLE、复杂笔刷、分镜脚本绘制和印刷级 CMYK 流程。
- 不宣称当前平台已经具备成熟的漫剧生产能力。
