# Figma Agent Brief: Extended Product Surfaces

## Task

Extend the existing VeyaTV Figma file as a second design phase. Preserve the
approved core workspace flows and typography system. Create high-fidelity
desktop and mobile artboards; do not return a written specification only.

Figma file:
`https://www.figma.com/design/G5eENqor13jwMlmKMkvJ3h`

## Product Character

Design a premium, elegant, mature AI short-drama and comic production factory.
It should feel like a quiet cinematic production desk, not a developer console,
a generic SaaS dashboard, a warm brown/beige theme, or a copy of LibTV or Jimeng.

Use competitor products only as references for clarity, restrained chrome and a
footage-first hierarchy. Real production images and footage remain the visual
protagonists.

## Theme Correction

- Ground: neutral near-black, approximately `#0D0E0E`.
- Sidebar: approximately `#101110`.
- Panels: approximately `#151615`.
- Raised surfaces: approximately `#1B1C1A`.
- Primary ink: paper white, approximately `#F3F2ED`.
- Muted text must remain accessible.
- Amber `#D8B56D` is limited to brand, current selection and active/running
  signals. Target about 3-5% of the visible screen.
- Do not wash the interface in warm brown, beige or sepia.
- No gradients, glows, glass, decorative orbs, purple/blue AI styling or
  low-contrast brown casts.

- Include meaningful empty, loading, error and disabled states where they alter
