# App 分享内测指南

更新：2026-11-06

## 目标

当前阶段只做朋友、面试官和团队的小范围分享内测，不提交 Apple App Store 或 Google Play，也不把备案与商店材料作为本轮门槛。

测试包必须做到：

- Android 使用直接 APK 安装。
- iOS 使用 TestFlight 或已登记 UDID 的 Ad Hoc 包。
- App 使用与 Web 相同的邮箱验证码账号。
- 测试者能在 3 分钟内安装，在 5 分钟内跑完一条核心路径。
- 问题能从 App 内反馈，附最少量的版本和设备信息。

## 测试账号

不要在仓库中写死共享密码、验证码或 Token。

- 测试者使用自己的邮箱接收验证码。
- 需要固定测试账号时，由账号持有人创建专用邮箱，再通过正常验证码流程登录。
- Web 与 App 必须使用同一个邮箱，才能检查跨端项目和额度。
- 测试结束后由账号持有人按隐私页面删除测试账号。

## 安装

1. 打开 `https://chenju.work/app`。
2. Android 下载最新 APK，并在系统浏览器中允许安装未知应用。
3. iOS 打开 TestFlight 邀请；Ad Hoc 设备必须先登记 UDID。
4. 首次启动完成 Veya Agent 引导。
5. 在“我的 → 检查内测更新”确认当前版本。

## 五分钟核心路径

| 步骤 | 操作 | 期望结果 |
|---|---|---|
| 1 | 用邮箱验证码登录 | App 与 Web 显示同一项目和额度 |
| 2 | 首次进入选择示例项目 | 当前集、场次和镜头来自真实项目 |
| 3 | 询问 Agent“现在最该处理什么” | 回答引用真实镜头、任务和下一步 |
| 4 | 打开整集草片 | 显示准备率、首帧阻断、480P 费用和预算 |
| 5 | 打开审片视频 | 时长不为 0，可播放、拖动和切换版本 |
| 6 | 下载当前视频 | 文件为 MP4，失败时提示视频而非图片 |
| 7 | 点麦克风说话 | 成功转写，或明确提示系统语音服务/权限原因 |
| 8 | 拍照做现场检查 | 相机权限正常，照片只在本次请求发送 |
| 9 | 从“我的 → 内测反馈”提交问题 | 返回反馈编号，失败时正文保留 |

## 首轮真机矩阵

| 设备 | 系统 | 重点 | 状态 |
|---|---|---|---|
| 小米 / Redmi | Android 14+ | 相机、语音服务、APK 安装、视频播放 | 待真机 |
| 华为 Android | Android 12+ | 无 Google 语音服务时的具体提示、相机和安装 | 待真机 |
| 低端 Android | Android 12+ | 启动速度、弱网、视频拖动和内存恢复 | 待真机 |

## 已知问题与验收边界

- 视频 Range/HEAD 已修复，仍需在 iPhone 和 Android 真机确认 5 秒视频时长与拖动。
- 语音识别已增加服务检测和更具体错误，仍需确认没有 Google 语音服务的 ROM 会显示正确说明。
- 推送、内购、Keychain/Keystore 后台恢复未在本轮自动测试中证明。
- iOS Ad Hoc 设备未登记时无法安装，这是分发方式限制，不是 App 崩溃。
- 华为、小米的相机扫码可能只打开网页；优先把 `/app` 链接发送到手机浏览器。

## 问题分级

| 级别 | 定义 | 示例 |
|---|---|---|
| P0 | 无法安装、无法登录、崩溃、数据丢失 | APK 无法安装、账号项目看不到 |
| P1 | 核心流程阻断但有替代路径 | 视频不能播放、语音服务不可用 |
| P2 | 视觉、文案和效率问题 | 按钮拥挤、状态不明显 |
| P3 | 建议和低频需求 | 新筛选、个性化设置 |

## 内测退出条件

- 至少 3 名测试者完成安装和邮箱登录。
- Android 与 iPhone 各至少 1 台完成视频播放和下载。
- 至少 1 台无 Google 语音服务 Android 显示明确错误或成功转写。
- App 内反馈能够返回编号，服务端能按账号读取。
- 所有 P0 清空，P1 有明确结论和修复排期。
