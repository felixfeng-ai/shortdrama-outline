D分镜台

把 9:16 的画面格当成主角：横向镜头带 + 下方镜头表 + 右侧检视器。一眼就知道这是个在拍片子的台子，不是写文档的地方。

方向说明

样机只用于选视觉与交互气质，不是最终页面。也可以只挑其中一个细节，在对话里告诉我（如：要 A 的深色 + B 的表格结构）。

A深色工作站

一句话气质
像 Cursor / Linear 的桌面客户端，一台在运转的机器
字体策略
IBM Plex Sans + IBM Plex Mono（编号、耗时、参数全等宽）
色彩策略
暗底三级面 #0F172A / #131C2E / #1E293B，强调色换成品牌朱砂的暗底版本 #E0605F
布局动作
左轨 + 主工作区 + 右检视器，靠「面」和 1px 线分区，一张卡片都没有
记忆点
顶部那条运行轨道：生成中 · 8.2s · token 数，机器在干活是看得见的

B亮色控制台 推荐

一句话气质
像 Figma / Airtable 这类网络应用：冷静、可扫读、没有装饰
字体策略
Manrope + Space Mono；中文系统栈，靠字重与字号拉层级
色彩策略
中性冷白 #F8FAFC + 细线 #E2E8F0，强调走青瓷 #0D9488（脱离朱砂的印刷感）
布局动作
角色与分镜变成可对齐的表，参数右对齐成列；卡片阴影全部删掉，只留 1px 线
记忆点
整页没有一个卡片，全靠线和留白切分——这是工具的语言，不是内容网站的语言

C对话工作台

一句话气质
像 Claude 的 Canvas：你的想法和 AI 的产出在同一条流里
字体策略
Work Sans + JetBrains Mono，正文略大（15px），对话优先
色彩策略
暖白 #FAFAF9 + 钢蓝 #0369A1，最轻的一套色彩
布局动作
单列 556px，生成结果作为「块」留在流里；分镜预览拉出成浮窗
记忆点
每个生成块头顶那枚「AI 生成」的来源徽标，产出物是可追溯的

D分镜台

一句话气质
像剪辑软件的监看台：影院黑 + 暖金，画面是主角
字体策略
Barlow Condensed + JetBrains Mono（窄体做标签，参数等宽）
色彩策略
#101012 / #151517 深底 + 暖金 #D9BE8A，沿用现在放映厅的色系并放大到全站
布局动作
横向镜头带 + 镜头表 + 右侧检视器，工作流从「写字」变成「过片子」
记忆点
一排 9:16 画面格排成胶片带，当前镜头带金边

色彩来源：A / B 的色板取自 ui-ux-pro-max 的 Developer Tool 与 Productivity / B2B 条目（#0F172A 系、#F8FAFC 系、青瓷 #0D9488），强调色按品牌替换。 它默认给「AI 工具」的推荐是 #7C3AED 紫 + #EC4899 粉，那是 AI 界面最同质化的一套，没有采用。C 用中性暖白 + 单一钢蓝，D 用品牌原有的影院色系（数据库无匹配条目，属通用深色媒体默认 + 品牌色）。
