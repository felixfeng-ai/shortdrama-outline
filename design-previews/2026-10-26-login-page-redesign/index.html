更年轻、更有排版态度，适合强调“制作工具”而不是“内容平台”。

方向说明

可以只选中意某个细节，在对话里组合，例如“要 A 的配色 + C 的资产监视器”。

A · Signal Desk / 指令台

像深夜的短剧制作指令台。记忆点是左侧项目链和右侧登录轨之间的明暗切换。

适合现有品牌延续，推荐原因是它最容易让老用户认出成剧。

B · Production Ledger / 制片账本

像编剧案头的制片账本。记忆点是暖纸、宋体标题和贯穿版面的细规则线。

适合强调文本与判断，代价是与当前深色工作台有明显断代。

C · Anchor Frame / 锚点监视器

像导演审片台。记忆点是角色锚点、影响提示和参考图锁定状态同时出现在首屏。

最适合突出护城河，代价是登录页会比常规账号页更密。

D · Studio Sheet / 白盒工作单

像工业制片工作单。记忆点是粗规则线、压缩标题和浅色黄绿的工作单结构。

适合建立独立品牌感，代价是客户可能需要适应更强的排版态度。

三个参数都可在上方拖动：视觉冒险度决定版式胆量，动效强度决定反馈多少，信息密度决定信息铺陈。点选方向后会打开确认层，可补充你的调整建议。
