VeyaFrame DIRECTION REVIEW

三套布局与视觉系统 · 2026-11-05

UI / PRODUCT DIRECTION

不是一个黑色主题，是三种不同的创作关系。

三套方案都沿用深色主调，但分别回答“编辑器如何安静”“创作主页如何有作品感”“画布如何成为 Agent 的主界面”。

方案 A最舒适 · 推荐主工作台

Quiet Studio

去掉常驻右栏和多余框线，把故事与人物内容重新变成主角。Agent 悬浮、按需打开。

  • 适合长时间写作与逐场修改
  • 最低迁移风险，沿用现有六步模型
  • 画面更克制，但视觉记忆点偏弱
打开完整 Demo
方案 B最有作品感

Creator Canvas

参考 LibTV 的创作主页节奏。中央画布是第一入口，模型、项目和作品作为第二层。

  • 首屏更直观，适合新用户和作品展示
  • 图片与画布给眼睛休息空间
  • 更适合首页，不足以替代深度编辑页
打开完整 Demo
方案 C最 AI-native

Node Desk

参考 Flova 的画布工作流。节点承载场次、镜头和产物，底部 Agent 指令栏贯穿整个创作。

  • 差异化最强，真实呈现整条生产链
  • 适合作为项目级画布与协作入口
  • 学习成本最高，新手需要更强的引导
打开完整 Demo

最终建议不是三选一，而是分层组合

B 做首页建立作品感和画布入口，A 做深度编辑承担长文本创作，C 做项目画布承载 Agent 与生产节点。三套共享黑色中性色、白色主操作和冷蓝运行态。
