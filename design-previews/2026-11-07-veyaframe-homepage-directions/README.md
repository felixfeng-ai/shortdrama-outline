# VeyaFrame 首页方向样机

最终确认方向 A 的完整首页效果见 `a-full.html`，正式产品代码未改动。

四个首页方向的可视化对比页。样机仅用于确认视觉与信息架构，不是最终页面，也不修改正式工作台。

## 方向

- A 石墨导演台：延续现有品牌，左侧项目导航，一句话输入与双路径最清楚。
- B 纸上制片厂：明亮编辑式首页，强调编剧和故事判断。
- C Agent 工作间：对话为主，试片和产物始终可见。
- D 制片墙：高密度项目与镜头管理，适合频繁制作。

## 交互

- 拖动“视觉冒险度 / 动效强度 / 信息密度”三个拨盘。
- 点击方向按钮或按 1-4 打开确认层。
- 在确认层填写调整建议，确认后回传选择。
- 也可以合并方向，例如“要 A 的布局 + B 的明亮感”。
