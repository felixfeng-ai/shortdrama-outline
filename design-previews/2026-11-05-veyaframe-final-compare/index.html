VeyaFrame 工作关系对比

基于真实示例项目 · 2026-11-05

画布退居工具，还是成为独立的工作层？

两版都使用同一个项目、同一套六步产物和同一套近黑视觉系统。差别只在信息架构：一版把所有动作收在单一工作台，另一版把首页、深度编辑和项目画布拆成三种工作视角。

方向一 单工作面

One Workspace

保留左侧菜单和原首页工作台，用“总览 / 创作 / 画布”在同一工作面切换，不再进入独立页面。

  • 对话输入是主角，技能和画布作为同层模式展开
  • 更接近即梦与原有线上的连续创作体验
  • 适合画布不是首页主体、但需要保留生产关系的阶段

方向二 三工作层

Three-Surface Studio

首页负责决定继续什么，深度编辑负责改文字与镜头，项目画布负责查看整条生产链。三者共享项目事实。

  • 最完整地呈现 Agent、文本与生产链的关系
  • 画布建立差异化，但不会抢占首页
  • 需要维护两套空间逻辑与更明确的返回路径

选择标准

如果现阶段目标是让用户更快理解并完成六步创作，方向一更稳；如果平台希望把“项目级画布 + Agent + 生产链”作为长期差异化，方向二更有空间。

两版都已实现项目切换、步骤查看、阻断定位、节点检查和 Agent 展开。
