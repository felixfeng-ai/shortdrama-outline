# 成剧 VeyaFrame · Native App 设计系统

> 原生 App 视觉基线。此文件只描述移动端；Web 继续使用仓库根目录的 `DESIGN.md`。
> 页面结构沿用豆包式轻量创作 Agent；项目、任务、账户保留为能力入口，不设置底部工作台。

## 1. 视觉主题

**暖白纸张上的轻量创作现场，不是项目控制台。**

- 首屏先给当前场次、一句创作问题和画面，不先展示六步进度与任务表。
- 当前项目退为顶部轻量胶囊，Veya Agent 只保留身份、上下文和一条有用判断。
- 画面用留白、细线、暖白层级和黑色主操作建立，不靠玻璃拟态和重阴影。
- 记忆点：暖白画布上一张大画幅分镜，下面紧接着“对话 / 创作”和输入区。

## 3. 排版

- 中文正文和 UI 使用系统字体栈。
- 数字、镜头号、时间码、额度使用 `SpaceMono`。
- 正文字号不低于 14；长文行高不低于 1.5。
- 层级靠字号、字重、颜色和间距，不用负字距。
- 中文标题字重 600，正文 400，弱化标签 500。

## 4. 布局

- 顶部安全区后显示品牌、项目切换和同步状态。
- 主内容在 4/8pt 节奏内滚动。
- Agent 是唯一主屏；项目、任务和我的通过顶部入口或运行状态进入原生栈页。
- 不设置底部四入口工作台导航，避免把 Web 的信息架构搬进 App。
- 输入区固定在 Agent 页底部，并为键盘和底部安全区留空间。
- 关键结果用画面或结构化状态呈现，不用长段 AI 自述。

## 5. 组件

- 项目胶囊：项目名、集数，不展示六步进度。
- 创作问题：一屏只出现一个，直接来自当前场次。
- 画面卡：大画幅分镜、场次名和镜头元信息。
- 模式切换：`对话 / 创作`，两端互斥。
- 快捷灵感：最多三条，点击后进入同一条创作输入路径。
- Veya Agent：身份、当前上下文、一条判断，不默认展开完整工具轨迹。
- 审片卡：9:16 画面、镜号、版本、来源、采用/退回。
- 现场 Take：检查结果之后记录备注、Canon 状态和好镜；照片仍只用于本次检查。
- 视频审片：当前时间码是批注定位点，通过、返修和定稿必须显示为互斥状态。
- 返修队列：只呈现开放退回和定稿记录，不扩展成项目管理工作台。
- 任务行：任务名、目标、状态、成本、时间、重试/停止。
- 单轮提案卡：用户输入、依据、影响面、成本，以及采用/不采用；不伪造后端写入。
- 输入区只保留一个模式入口；项目上下文由 Veya Agent 身份行承担，不在输入框内重复。
- 语音输入：权限等待、听写、结束和错误必须有状态；`aborted` 属于控制流，不显示为错误。
- 同步状态：同步中、已同步、本地草稿、同步失败并可重试；失败时保留最后一份可用内容。
- 场景预览按地点切换码头、门口和室内构图；没有真实关键帧时不冒充生成图。
- Agent 执行态明确最多 3 次模型调用，结果区显示实际消耗；降级回答必须说明未执行工具。
- 提案卡在确认前只表示待确认建议；确认写入后显示真实分镜版本号。
- 版本冲突必须保留建议并提示 Web/其他设备已更新，不能覆盖新版本。
- 视频缺首帧时，生成页必须提供“在 App 生成首帧”动作，成功后立即作为当前镜头视频输入。
- 缺首帧时同时保留“直接生成视频”兜底；使用文生视频时必须在费用与状态附近说明。
- 所有可点击目标至少 44×44pt，按压立即反馈。

## 6. 深度

1. canvas
2. surface
3. elevated
4. overlay
5. modal scrim `rgba(25,26,24,0.68)`

亮色层优先用背景明度和发丝线建立；阴影只用于模式切换和浮层。

## 7. Do / Don't

- Do：首屏让用户立刻继续当前场次。
- Do：让 Agent 身份和当前项目上下文持续可见。
- Do：运行任务只以一条轻量状态出现，点开再管理。
- Do：把回答落到镜头、版本、任务或导出。
- Don't：把 Web 六步工作台塞进 App 首屏。
- Don't：使用紫蓝渐变、霓虹、纯黑、玻璃卡片墙。
- Don't：在 App 内加载 Web 工作台。

## 8. 动效

- 页面进入只做 160–220ms 的透明度和 6px 位移。
- 按压反馈 100–160ms。
- 运行点使用低频呼吸，只表达状态。
- 支持系统减少动效设置。
- 键盘触发操作不做动画，不用装饰性无限动画。

## 9. 页面清单

1. Agent 首页：项目胶囊、创作问题、画面、对话/创作、快捷灵感、输入区。
2. 项目页：项目列表和切换。
3. 任务页：待确认、运行中、失败与审片入口。
4. 我的页：从顶部账户入口进入，展示额度、设备、通知、隐私和订阅。
5. 审片页：全屏关键帧、版本比较、采用与退回。
6. 登录页：邮箱 → 6 位验证码 → 登录；与 Web 共用账号，不使用密码。
7. 项目操作：加号打开原生新建弹层；列表点击切换；底部提供 ZIP 导入和示例载入。
8. 首次启动：Veya Agent 价值页，主操作进入示例剧，次操作进入项目页，也可跳过；完成状态只保存在本机。
9. 能力地图：从首页上下文行进入，列出画面、视频、草片、审片和检查能力。
10. 返修队列：按待返修与待定稿筛选开放镜头记录，可回到对应审片。
