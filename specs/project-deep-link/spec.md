# 项目深链与分享入口

> 目标：项目、当前步骤和浏览历史组成稳定 URL，刷新、分享和 PWA 打开都能恢复同一上下文。

## 能力

- URL 使用 `?project=<projectId>&step=<StepKey>` 定位项目与步骤。
- 只打开当前登录用户或匿名会话有权访问的项目。
- 项目切换、新建、载入示例和生成首个项目时同步 URL。
- 无效、已删除或无权访问的项目不泄露其他项目内容。
- 项目条提供可复制的分享链接，链接保留当前步骤。

## 场景

### P1 打开项目深链

**Given** 当前身份拥有项目 A，链接为 `/?project=A&step=visuals`

**When** 用户打开或刷新链接

**Then** 工作台打开项目 A 并定位到视觉定妆步骤。

### P2 切换项目同步历史

**Given** 用户在项目 A

**When** 用户切换到项目 B

**Then** URL 更新为项目 B，浏览器后退可回到项目 A。

### P3 失效链接安全回退

**Given** URL 指向不存在、已删除或不属于当前身份的项目

**When** 页面初始化

**Then** 不读取该项目内容，回退到当前身份最近项目（没有则打开空白工作台），并移除 URL 中的无效项目参数。

### P4 复制分享链接

**Given** 用户正在查看一个已保存项目

**When** 用户点击「复制项目链接」

**Then** 复制包含项目 id 与当前步骤的站内链接，并给出复制成功反馈。

## 验收

- URL 解析与同步函数有单元测试。
- 页面初始化、项目切换、新建、删除和前进后退均有源码回归断言。
- 桌面和手机浏览器打开深链、刷新、切换与后退无控制台错误或横向溢出。
