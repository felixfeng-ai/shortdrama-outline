# Visual Polish V1

## 目标

修复确认稿落地后的局部视觉问题，不改变页面信息架构和真实业务行为。

## 能力点

### R1: 头像几何

- 顶栏账号头像外层与内部头像层均为 `30px`。
- 外层不使用旧 `.h-install` 横向按钮的左右 padding。
- 头像内容在圆形中心，不向右溢出。

### R2: 登录页主题与文案

- 登录页使用 `#08090A / #101214 / #F2F2EE / #8DC8DC`。
- 不再使用 `#C4D98A` 作为品牌、标题强调或主操作色。
- 标题突出“人的判断 + 项目一致性”。
- 说明文案突出 Canon、跨镜一致性、确认后写入、版本可追溯和跨设备继续。

### R3: 图标和聚焦态

- 平台图标统一继承当前主题色。
- 品牌 V 标使用反相白，不使用旧绿色。
- 输入框聚焦只使用一层冷蓝提示，不再叠加绿色 2px outline 和粗边框。
- 创作主输入框聚焦时不再显示外圈高亮边框；保留常态弱边界、光标与背景层级。
- 全局深色主题的低中阶 `--c-accent-*` 与 Agent 舱强调块改映射到冷蓝；旧鼠尾草绿 rgba、硬编码背景和反相文字不再出现。

### R4: 创作额度命名

- 内测阶段不把每日配额命名为可充值积分。
- 用户界面统一使用“今日创作额度”或“创作额度”。
- 文案清楚表达每日恢复，不暗示可购买余额。

### R5: 右侧执行计划

- `342px` 右栏中的执行计划改为单列。
- 执行步骤、额度、读取范围、确认节点和产出预览不得被压成竖排单字。
- 右栏内部不再保留宽版页面的 `60px + 280px` 双栏布局。

## 验收

- 源码测试覆盖头像尺寸、登录页 copy/token、focus 颜色、额度命名和计划单栏。
- 源码测试覆盖全局旧绿色清理与深色工作区冷蓝强调斜面。
- Playwright 验证头像中心误差不超过 1px。
- Playwright 验证输入聚焦计算色不含旧绿色。
- Playwright 验证右栏执行计划列数是一列，文字宽度正常。
- 全量测试、类型检查和生产构建通过。
