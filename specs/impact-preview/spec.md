# 修改前影响预览

## 目标

总览执行确定性批量返修前，先展示真实影响范围和成本，用户确认后才写入新版本。

## 能力点

### IP-1 影响计算

- 使用最新镜头、定妆、地点和已生成资产计算实际会改变的镜头。
- 统计受影响集数、场次数、镜头数和已出图镜头数。
- 确定性锚点修复的模型费用和创作额度必须为 0。

### IP-2 预览交互

- 总览点击“修复提示词”先打开影响预览，不直接写库。
- 预览明确说明：只修改 Prompt、不调用模型、不扣额度、会生成新快照。
- 用户取消时不修改任何内存或服务端数据。
- 用户确认后才调用批量返修接口并更新工作台。

### IP-3 边界

- 没有实际受影响镜头时不打开空确认框。
- 接口返回零变更时不制造新版本。
- 保存失败时关闭忙碌态并保留预览，允许重试。
