# 工作台当前任务决策区

## 目标

工作台首屏先回答三个问题：当前在做什么、什么在阻塞、下一步该做什么。状态必须复用现有项目事实与 `buildTodoList()`，不新增评分、估算或伪数据。

## 能力点

### 1. 当前任务

- Given 项目已有任一内容，When 工作台渲染，Then 显示当前应处理步骤及已有的真实产出状态。
- Given 项目为空，Then 故事输入仍优先出现，决策区提示先写下故事想法。

### 2. 唯一阻塞

- Given `todoItems` 中存在 `kind: "fix"`，Then 显示第一条明确阻塞及其对应处理入口。
- Given 没有修复项，Then 显示“未发现明确阻塞”，不伪造告警。

### 3. 下一步

- Given `todoItems` 中有主链推进项，Then 第一项 `kind: "next"` 作为下一步动作，按钮跳到该项的 `step`。
- Given 主链已完成但仍有修复项，Then 阻塞区承担动作，下一步区只说明“清除阻塞后再交付”，不重复同一按钮。
- Given `todoItems` 为空，Then 明确显示当前主链已处理完。

### 4. 布局与导航

- 六步轨道保留为次级导航。
- 有项目的状态决策区位于故事输入之前；空项目位于故事输入之后。
- 桌面与 390px 宽度不得出现页面级横向溢出；触控目标不小于 44px。

## 非目标

- 不修改生成接口、版本、Canon 或待办算法。
- 不删除工作台后续的项目管理面板。
