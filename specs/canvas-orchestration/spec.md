# 实时画布与节点编排基础层

> 第 3 项先建立通用画布与协作基础，不把视频、时间线或渲染节点写死在图模型里；这些后续作为新的节点类型接入。

## 目标

让画布从“只读项目可视化”升级为可编辑的项目编排面：节点可布局、可连接、可补充人的判断，并能在刷新和多个浏览器标签之间保持一致。

## 能力点

### CV1 · 通用节点模型

- 画布图包含 `nodes` 与有向 `edges`，每个节点有稳定 id、类型、标题、正文、坐标和可选步骤引用。
- 系统节点覆盖人物、三幕、分集、定妆、场次、地点、分镜；系统节点可移动、可连线，但不可删除。
- 用户可新增“备注”“判断”“交付物”三类节点，并编辑标题与正文。
- 默认图复用现有六步依赖，不从输出文案猜测关系。

### CV2 · 节点编排

- 桌面支持拖动节点、缩放、平移和适应视图。
- 用户可从节点发起连接，再选择目标节点；拒绝自连和重复边。
- 删除自定义节点时同时删除相关边；系统节点不能删除。
- 选中节点显示属性、上下游连接和真实入口；系统节点可跳回对应工作台步骤。
- 390px 窄屏可完成选择、移动摘要、编辑、连接和删除，不产生页面级横向溢出。

### CV3 · 自动保存与冲突保护

- 编辑后自动保存到项目级 `canvas_graphs`，刷新后恢复。
- 每次保存递增 revision；客户端提交 expectedRevision，服务端不一致时返回 409 与最新图。
- 保存失败不伪装成功，界面显示“未保存 / 冲突 / 失败”并允许重新读取。
- 空项目同样有稳定默认图；删除项目时图级联清除。

### CV4 · 多标签页实时同步

- 使用 BroadcastChannel 在同一 origin、同一项目的标签页之间同步已保存图和编辑中的节点位置。
- 界面显示真实同步状态与当前可见标签页数量，不宣称跨设备实时协作。
- 远端消息晚到不得覆盖更高 revision；revision 相同但内容不同时依靠服务端 409 收口。
- reduced-motion 下关闭节点入场、连线绘制和抽屉位移动画。

## 非目标

- 不做跨设备 WebSocket 协作、成员光标、评论线程或权限角色。
- 不在本项接入视频、TTS、时间线、渲染任务节点。
- 不把画布图替代六步快照；画布保存的是编排关系与人工节点，不复制正文资产。
