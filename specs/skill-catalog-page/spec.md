# Skill 创作入口页

## 目标

把 Skill 从技术概念呈现为短剧创作入口。首屏以任务输入为主，下方用作品化卡片展示官方 Skill；右下角常驻 AI 场记入口，可基于当前项目执行现有 Agent 工具。

## P0 能力点

### S1 · 创作入口

- 顶部提供 `/skill` 标题、大输入框、素材/资产/选择 Skill 工具和发送按钮。
- 快捷任务可一键填入输入框。
- 点击 Skill 卡会把该技能任务填入输入框，并打开执行计划；计划确认前不调用模型、不写入项目。

### S2 · Skill 画廊

- 展示官方、小说改编、故事医生、Canon、连续性、交付预检、成本规划。
- 支持推荐/收藏/我的，分类筛选与关键词搜索。
- 卡片使用真实场景或产品产物缩略图，不使用纯色占位。
- 点击卡片不自动扣额度，不直接修改项目。

### S3 · AI 场记

- 页面右下角常驻“问场记”入口。
- 抽屉打开后读取当前项目状态，复用现有 `runAgentLoop`、工具 schema 和 executor。
- 工具轨迹显示技能匹配、项目读取和检查过程。
- 写操作仍只返回现有待确认卡，不在本页偷偷写入。

### S4 · 响应式

- 桌面三列 Skill 画廊。
- 手机单列画廊，输入区与 Agent 抽屉不横向溢出。

## 验收场景

### Scenario S1

**Given** 用户打开 `/skills`
**When** 点击“小说 / 剧本改编”
**Then** 输入框出现改编任务，并显示执行计划、前置与写入边界，不调用模型。

### Scenario S2

**Given** 用户搜索“分镜”
**When** 画廊过滤
**Then** 只显示镜头连续性相关 Skill，并保留搜索和分类状态。

### Scenario S3

**Given** 用户点击“问场记”
**When** 输入“现在还有哪些要处理”
**Then** 场记读取当前项目，并复用项目状态工具回答。

## 不在本期

- 用户上传自定义 Skill。
- Skill 脚本执行沙箱。
- Skill 市场、关注、付费和作者体系。
