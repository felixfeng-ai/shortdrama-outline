# 工作台信息层级收敛

> 目标：每一步只展示当前任务需要的主体内容；全局能力保留入口，不重复占据正文。

## 1. 能力

- Story Command 在核心人物步骤完整展开。
- 其他步骤只显示项目源想法摘要，用户可主动展开编辑。
- 编辑源想法时提示下游产物可能需要重跑。
- 本地图库只在定妆和场景完整展开；核心人物显示紧凑摘要。
- 分镜只显示缺参考图摘要，并跳到定妆处理。
- 项目包、Markdown、复制大纲统一收进项目条导出菜单。

## 2. 硬边界

- 不删除任何业务能力。
- 不改变当前 Signal Desk 主题、顶栏和六步导航。
- 不在非人物步骤显示“生成核心人物”主操作。
- 导出操作仍必须有内容时才可用。
- 移动端不得增加横向溢出。

## 3. 场景

### T1 Story Command

**Scenario T1.1**
Given 用户正在三幕、分集、定妆、场景或分镜
When 页面渲染
Then 只显示项目源想法摘要和编辑入口，不显示大输入框和生成人物按钮。

### T2 本地图库

**Scenario T2.1**
Given 用户在定妆或场景
Then 展示完整本地图库。

**Scenario T2.2**
Given 用户在分镜且存在缺参考图角色
Then 只显示缺图摘要和“去定妆”入口。

### T3 导出

**Scenario T3.1**
Given 项目已有内容
When 用户点击项目条“导出”
Then 菜单提供项目包、Markdown 和复制大纲，正文底部不再重复导出卡。

## 4. 验收

- 信息层级静态测试覆盖每一步。
- 导出能力仍可调用。
- 全量测试、类型检查、生产构建和桌面/手机浏览器验收通过。
