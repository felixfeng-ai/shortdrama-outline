# 全局产物抽屉

## 目标

给用户一个项目级的产物入口，集中回答“生成了什么、最新是哪版、这一版改了什么、还有哪些 Agent 提案等我确认”。

## 能力点

### GA1 · 全局入口

- 项目条提供“产物”按钮，并显示当前已有产物的种类数量。
- 没有项目时按钮禁用。
- 点击打开全局抽屉，不切换当前创作步骤。

### GA2 · 产物版本

- 左侧列出故事、人物、三幕、分集、定妆、场次、地点、分镜。
- 每类显示最新版本、条目数量和最近更新时间。
- 右侧展示所选类别的历史版本；可选择一版与前一版比较。
- 差异只描述真实结构和值变化，不显示伪评分。

### GA3 · 确认队列

- 汇总当前 Agent 会话中的待确认卡。
- 每项显示类型、目标、摘要和建议步骤。
- 点击“在 Agent 中处理”打开工作舱，不自动确认或写入。
- Agent 卡确认或忽略后，队列同步移除该项。

### GA4 · 视觉与响应式

- 沿用 Signal Desk 石墨底、发丝线和鼠尾草绿，不新增第二套视觉语言。
- 桌面使用左侧产物列表 + 右侧版本/差异；390px 单列纵向展示。
- 页面不横向溢出，主要按钮触控目标不小于 44px。

## 非目标

- 不在抽屉内直接恢复快照。
- 不替代项目导出、生产台账或 Agent 对话。
