# App Demo 检修规格

## 能力点

### R1 · 项目切换

- 项目面板支持 `Esc` 关闭。
- 面板打开后焦点进入面板，`Tab` 不会逃出弹层。
- 关闭后焦点回到项目入口。
- 选择另一个项目后，项目名称与当前场景同步更新，对话回到空态。

### R2 · 对话输入

- 输入框随内容自动增高，高度限制在 36px 到 88px。
- `Enter` 发送消息，`Shift + Enter` 保留换行。
- 思考中禁止重复提交，停止按钮可以结束等待。
- 滚动定位尊重 `prefers-reduced-motion`。

### R3 · 导航与恢复

- 点击品牌标回到聊天首页。
- “稍后决定”回到对话。
- “查看改动”展开当前确认项的细节，而不是无响应。
- 切换到创作页时从内容顶部开始阅读。
- 展开改动明细后，将明细滚动到输入区上方的可见区域。

### R4 · 可读性与响应式

- 关键中文操作与说明不小于 12px，正文保持 14px 以上。
- 375px、390px 和桌面视口无横向溢出。
- 所有可见按钮触控目标不小于 44px。

### R5 · 本机会话

- 不提供虚假的登录状态，顶栏显示当前为本机会话。
- 点击入口后，用底部面板说明匿名身份、记录范围、图片边界与跨设备同步情况。
- 面板具备 `Esc`、焦点陷阱和焦点返还。

### R6 · 附件

- 加号按钮打开附件菜单，可引用本机图片或当前场次。
- 图片只显示文件名，不读取或上传二进制内容。
- 附件在输入区显示为可移除的标签，并随消息进入对话气泡。
- 有附件时可以不带文字发送；发送后清空附件。

### R7 · 语音

- 浏览器支持语音识别时，点击麦克风开始转写，再次点击停止。
- 识别结果写回输入框，不自动发送。
- 浏览器不支持或权限失败时，显示可恢复的下一步说明。
- 麦克风按钮通过 `aria-pressed` 暴露录制状态。

## 验收场景

- Given 项目面板已打开，When 用户按 `Esc`，Then 面板关闭且焦点返回项目入口。
- Given 用户输入多行内容，When 使用 `Shift + Enter`，Then 光标换行而表单不提交。
- Given 用户正在等待 Agent，When 点击停止，Then 等待结束且消息不被重复提交。
- Given 用户选择“雾中来客”，Then 顶栏与当前场景更新，旧对话不残留。
- Given 用户从已滚动的长对话进入创作页，Then 页面从创作流程顶部开始展示。
- Given 用户展开改动明细，Then 明细完整出现在输入区上方，不被遮挡。
- Given 用户点击“本机”，Then 打开匿名会话说明，且不会出现虚构的登录成功状态。
- Given 用户引用一张本地图片，Then 输入区出现文件标签，发送后附件随用户消息展示。
- Given 浏览器不支持语音识别，When 点击麦克风，Then 显示“改用键盘”的恢复提示。
- Given 页面运行于 375px 或 390px，Then 无横向滚动，按钮仍可点击，控制台无错误。
