# Production Hardening P3

> 本轮补齐外部生成视频回传：用户从即梦、可灵或其他工具下载 MP4 后，可以绑定到具体镜头并继续进入时间线与动态分镜。

## R1 服务端导入

Given 项目所有者持有当前镜头 id
When 上传一个 MP4 文件
Then 服务端只接受 MP4、最大 80MB，并校验文件头
And 使用 FFprobe 读取真实时长与尺寸，时长必须在 1～15 秒
And 视频写入 generated 目录，并创建成功的生成任务与生成资产
And 新资产自动采用，旧视频版本保留为历史候选
And 不调用模型、不扣额度

## R2 安全边界

- 只允许当前项目 owner 为该项目中的真实镜头导入。
- 非 MP4、伪装文件、空文件、超限文件、无法探测的媒体一律拒绝。
- 生成任务 provider 固定为 `external-upload`，便于台账区分内部生成与外部回传。
- Nginx 为该入口提供独立请求体上限，不放大全站默认上传上限。

## R3 镜头视频工作区

Given 用户进入分镜工作区的“镜头视频”模式
When 展开选择视频镜头
Then 每个镜头行提供“导入外部视频”
And 导入中、失败和成功都有可见状态
And 成功后候选区立即出现“外部导入”版本，并标记已采用

## R4 下游事实

- 刷新项目后，外部视频仍是当前采用的镜头视频。
- 动态分镜优先使用该已采用视频，不再使用该镜首帧。
- 时间线与候选历史读取同一生成资产，不另建外部视频表。

## 浏览器验收

- E2E 从示例项目进入“镜头视频”，向第 1 镜导入真实 MP4。
- 验证候选区出现“外部导入 / 已采用”。
- 打开动态分镜后，镜头序列变为 1 条视频 + 4 张首帧。
- 覆盖 1440px 与 390px 截图，无横向溢出和控制台错误。

## 非目标

- 不接入外部供应商 API。
- 不解析第三方项目文件或工作流 JSON。
- 不自动发布到平台。
- 不在本轮支持音频、图片或 GPL 等更多上传类型。
