# 低频项目工具面板

## 目标

把实体批注、跨项目资产库和版本分支从所有步骤正文中移出，收进项目条里的统一“项目工具”入口。默认页面只保留当前创作任务，低频工具按需打开。

## 能力点

### PT1 · 单一入口

- 项目条提供带图标的“项目工具”按钮。
- 没有已保存项目时按钮禁用并说明原因。
- 页面正文不再常驻三个工具的完整表单。

### PT2 · 工具面板

- 打开后使用模态工具面板，包含“实体批注 / 跨项目资产 / 版本分支”三个页签。
- 每个页签用一句话解释用途与边界，用户不需要先理解内部概念。
- 同一时间只挂载当前页签内容；关闭面板时不挂载三个重组件。

### PT3 · 可访问性

- 面板使用 `role="dialog"` 与 `aria-modal="true"`，支持 Escape、遮罩关闭、焦点进入和关闭后焦点恢复。
- 桌面居中，390px 下占满可用视口且不横向溢出。
- 主要按钮触控目标不小于 44px。

### PT4 · 原有能力

- 三个工具的保存、复用、清空、创建分支逻辑保持不变。
- 项目归属、确认前不写正文和“不带本地图片”的边界文案继续保留。

## 非目标

- 不新增新的批注、资产或分支后端能力。
- 不重做三个工具内部的业务表单。
