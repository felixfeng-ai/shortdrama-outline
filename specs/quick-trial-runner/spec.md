# 快速试片断点恢复

## 目标

快速创作在页面关闭、刷新或切换项目后，仍能从服务端记录的最后完成阶段继续。
恢复只复用现有项目快照和生成任务，不复制角色、分集、分镜或首帧数据。

> 统一入口、三档范围和预算冻结规则以 `specs/unified-quick-entry/spec.md` 为准。

## 状态模型

- `phase` 只记录最后一个已完成的阶段，初始值为 `start`。
- `status` 记录 `active / failed / completed`，用于区分进行中、失败待重试和已完成。
- `visualApproved` 只会在用户确认视觉阶段费用后设为 `true`。
- 页面关闭时尚未完成的步骤不会提前推进；重新打开后从该步骤安全重试。
- 只有用户开始前选择 `video` 范围时才会保存视频授权并生成第 1 镜一条视频。

## 恢复场景

### R1 故事阶段恢复

Given 最后完成阶段是 `characters`

When 用户刷新页面

Then 从三幕大纲继续，不重新生成核心人物。

### R2 视觉确认

Given 第一集已完成但用户尚未确认视觉费用

When 用户刷新页面

Then 只恢复第一集完成状态，不自动生成定妆、场次、分镜或首帧。

### R3 视觉阶段恢复

Given 用户已经确认视觉费用且最后完成阶段是 `scenes`

When 用户刷新页面

Then 从分镜继续，已生成的角色定妆和场次保持不变。

### R4 完成与失败

- 到达用户选择的故事、首帧或视频终止点后状态为 `completed`，恢复时只展示结果。
- 任一阶段失败时保留最后完成阶段与真实错误；重试从失败步骤开始。
- 没有已完成阶段时使用 `start`，首次重试仍从核心人物开始。

## 非目标

- 不为快速试片新增第二套创作数据。
- 不越过用户选择的范围，也不在恢复时跳过范围与预算确认。
- 不在本轮实现后台常驻执行；关闭页面后由下一次打开恢复。
