# 原生 App · 单轮 Agent 提案

## 1. 目标

把当前 Agent 首页里静态的快捷灵感和发送按钮，补成一轮可操作、可停止、可确认的本地 Agent 交互。保持豆包式轻量首页和 AI 场记身份，不新增聊天历史、工作台导航或第二套视觉。

本轮只验证交互状态与信息层级，不接真实 Agent API、不写项目数据、不扣额度。真实执行留给后续账号与工具调用阶段。

## 2. 硬边界

- 不重排 Agent 首页，不增加通用聊天气泡流。
- 快捷灵感与手动输入走同一条发送路径。
- 一屏只保留一个当前提案，不并发多个 Agent 任务。
- 提案必须显示依据、影响面和成本，不伪造模型结果。
- 执行态可停止；停止后保留用户输入，允许重新发起。
- 所有按钮不小于 44×44，适配 375 和 390 宽。

## 3. 能力与场景

### R1 填入快捷灵感

Given 用户处于对话或创作模式
When 点击一条快捷灵感
Then 文案进入底部输入框，不立即发送。

### R2 发起一轮 Agent

Given 输入框有非空内容且当前没有运行中的一轮
When 点击发送
Then 记录本轮用户输入，进入执行态，展示当前执行步骤。

并且空输入、仅空白字符或已有运行中任务时不能重复发起。

### R3 停止执行

Given 本轮处于执行态
When 用户点击停止
Then 执行态结束，保留本轮输入，不生成提案。

### R4 完成提案

Given 本轮处于执行态
When 本地执行完成
Then 展示一条 AI 场记提案，包含目标、依据、影响面和成本。

### R5 采纳或继续

Given 已展示提案
When 用户采纳
Then 页面进入已选择状态，并提供“查看第 17 镜”入口。

When 用户放弃
Then 回到 AI 场记空闲态，输入框清空。

### R6 模式

Given 用户切换对话或创作
Then 快捷灵感与 AI 场记说明跟随模式变化，已提交的本轮结果不被改写。

- 检查长中文文案、键盘打开、底部安全区和无横向溢出。
