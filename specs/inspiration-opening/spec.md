# 灵感开题与选题雷达

## Goal

让完全不知道写什么的用户，不输入关键词也能在三次选择内得到三个差异化、可制作的短剧方向，并把确认结果写回现有项目想法，继续进入六步工作流或 Agent。

## Requirements

### R1 无空白开题

- 首次创作状态显示“开题助手”。
- 用户可以直接写、让平台帮开题，或从市场选题开始。
- “帮我开题”不要求先输入关键词。
- 用户只需选择目标观众、核心情绪和制作约束。

### R2 三个差异化方向

- 一次生成三个方向。
- 三个方向不能只替换人物名或地点。
- 每个方向包含一句话故事、3 秒钩子、主要冲突、情绪落点、差异点、角色/场景规模、制作难度、成本和风险。
- 用户点击“使用这个方向”后，方向写入现有 `idea`，推荐题材同步到题材选择。

### R3 市场选题雷达

- 市场选题只提供结构化题材信号，不提供可复制的完整作品内容。
- 每条信号带来源、快照时间、趋势、拥挤度、制作难度和合规风险。
- 首期使用人工整理的编辑样本，明确标注非实时排名。
- 用户可以从信号进入开题，不直接生成同款作品。

### R4 现有体验保持

- 不改变现有首页、六步工作流、Agent、额度、快照和回滚边界。
- 字体、颜色、圆角、间距和交互密度沿用当前工作台。
- 桌面和手机不得出现横向溢出或文字遮挡。

### R5 首页创作入口与双出口

- “创作”模式在不离开当前页面的情况下提供“不知道怎么开始”入口。
- 用户确认方向后，可以选择进入六步制作或交给 Agent。
- 两条路径共用同一个 `idea` 快照、推荐题材和项目事实。
- 当前项目已有内容时，不得覆盖原项目；应新建项目承载新方向。
- 当前项目为空时，可直接复用当前项目。

## Acceptance

- 空关键词可得到三个方向。
- 三个方向成功写入当前项目想法。
- 市场雷达有来源和时间，且不暴露未经授权的完整榜单内容。
- 原有输入想法、关键词联想、题材选择和生成人物能力继续可用。
- 全量测试、类型检查和生产构建通过。
