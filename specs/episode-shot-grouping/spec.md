# 分镜按集分组与集号修正

## 目标

让全剧分镜从一条平铺长列表变成可扫读的集级结构，并允许用户修正模型漏写或写错的集号。

## R1 · 集级分组

### 场景 R1.1 · 按集聚合

Given 分镜的 `episode` 分别为 2、1、2、0
When 打开分镜列表
Then 先显示「未标注」组，再按第 1 集、第 2 集升序显示；组内保持原镜头顺序

### 场景 R1.2 · 集级摘要

Given 某一集包含多个镜头
Then 集头显示镜头数、时长合计、缺图镜头数和需返修镜头数

### 场景 R1.3 · 场次分段

Given 同一集内连续镜头的 `scene` 标签相同
Then 这些镜头归入同一个场次小标题；标签变化时另起一段，不以跨集同名场景合并

### 场景 R1.4 · 收起与展开

Given 分镜已按集分组
When 用户点击集头
Then 可收起或展开该集，不改变任何镜头数据

## R2 · 集号修正

### 场景 R2.1 · 就地修改

Given 某个镜头的集号不正确或为 0
When 用户从镜头卡集号下拉中选择 1..总集数
Then 只修改该镜头的 `episode`，其他镜头不变，并立即移动到对应集组

### 场景 R2.2 · 未标注可见

Given `episode = 0`
Then 镜头显示「未标注」，不自动猜成第 1 集

## 非目标

- 不改变全剧镜号。
- 不改变 CSV、执行单和离线分镜表的字段。
- 不自动把未标注镜头归集。
- 不新增集号筛选或 URL 状态；本阶段先解决分组、摘要和就地修正。
