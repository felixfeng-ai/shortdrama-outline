# 原生 App 差异化能力 v1

## 目标

继续沿用轻量创作 Agent 首页和暖白视觉，不把 Web 工作台搬进 App。本批只补能形成差异化的五项能力：可核验的视频预算提案、账号级会话同步、现场连续性检查、按集节奏分析和海外版本审片。

## 能力点

### R1 Agent 视频预算提案

- Agent 可以生成待确认的视频计划卡，不直接创建付费任务。
- 卡片必须包含镜头数、单镜时长、模型、分辨率、预计费用和预算上限。
- 费用由服务端价格表计算，不信任模型自由生成的金额。
- 非视频、未完成或已锁定目标不能进入视频计划。

### R2 Agent 会话跨设备同步

- 项目 Agent 会话写入服务端项目线程，同一账号换设备后可以恢复最近一轮对话。
- 本地 SecureStore 继续作为离线和弱网回退，不替代服务端会话。
- 同步失败不能阻断 Agent 回答；不从本地缓存复制生成图片、Token 或正文。

### R3 现场连续性检查

- 用户可以拍摄或选择一张现场照片，并指定当前镜头。
- 服务端读取当前人物定妆、地点锚点、镜头提示词和 Canon，再调用视觉模型比较。
- 结果按人物造型、地点结构、道具、光线和构图列出偏差；每项可给出提示词修正建议。
- 照片只随本次请求发送，不写入项目快照或生成资产库。

### R4 按集节奏与悬念分析

- 按集展示开场/结尾钩子、对白密度、平均镜头时长和镜头数。
- 对比成剧的竖屏短剧基准，明确标出偏长、偏密、偏慢或钩子过短。
- 分析只读，不自动改写分集或镜头。

### R5 海外版本审片

- App 只做审阅：选择海外分支后查看字幕上限、目标平台、文化适配规则和最新审计问题。
- 支持阻止项、提醒项和证据定位，不在 App 内做完整翻译工作台。
- 没有海外分支或审计时显示真实空态，不伪造结果。

## 页面与交互

- 首页新增一行三个紧凑工具入口：现场检查、节奏分析、海外审片。
- 三个新页面沿用现有 `ScreenHeader`、`Panel`、`PrimaryButton` 和暖白 tokens。
- 每个页面只有一个主角：现场照片、分集节奏表或海外审片问题列表。
- 390 和 375 宽度无横向溢出；长中文、空态、加载、失败态都要可见。

## 验收

- 每个能力点先有失败测试，再实现到通过。
- App/Web 全量测试、类型检查和生产构建通过。
- 新增页面进行真实截图验收；真机权限和视觉模型调用如未执行，必须如实标注。
