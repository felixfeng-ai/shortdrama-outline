# 创作契约 V2

> 状态：已实现，等待产品验收
> 日期：2026-11-04  
> 优先级：P0，差异化基础能力

## 1. 目标

把现有 4 字段「创作意图」升级为能约束全流程生成的「创作契约」。
它不替用户生成更多内容，而是回答三个问题：

1. 这部片向观众承诺了什么？
2. 观众持续追看的具体回报是什么？
3. 最终必须兑现怎样的情绪或价值？

契约进入人物、三幕、分集、场次和分镜的生成上下文；字段变化时，
沿用现有血缘与过期提示，让用户知道哪些下游产物基于旧契约生成。

## 2. 数据模型

在 `CreativeBrief` 上增量增加三个字段，现有四个字段不变：

| 字段 | 界面名称 | 含义 | 上限 |
|---|---|---|---|
| `premise` | 故事承诺 | 谁想要什么、被什么阻止、失败要付出什么代价 | 160 |
| `payoff` | 追看回报 | 观众持续追看的具体情绪回报，不写泛化类型 | 100 |
| `destination` | 最终落点 | 结局必须兑现的情绪、关系或价值变化 | 100 |

原有字段：

- `emotion`：核心情绪
- `audience`：目标观众
- `references`：参考气质
- `redline`：不想变成什么

旧项目缺少新字段时按空字符串读取，不迁移数据库，不修改已有内容。

## 3. 能力点与场景

### CC1 向后兼容

**Given** 旧项目只保存了原四个字段  
**When** 读取项目上下文或导入旧项目包  
**Then** 新字段为空，旧字段保留，页面和生成不报错

**Given** 所有字段都为空  
**When** 构造任何生成 Prompt  
**Then** Prompt 与升级前逐字一致，不增加空标题或空约束

### CC2 契约校验与摘要

**Given** 用户填写了故事承诺、追看回报和最终落点  
**When** 页面展示契约摘要  
**Then** 显示「核心契约已就绪」

**Given** 只填写了部分字段  
**When** 页面展示契约摘要  
**Then** 显示已填写项数量，不阻止生成

**Given** 任一字段发生修改  
**When** 计算契约签名  
**Then** 签名变化，已有下游产物可被标记为基于旧契约

### CC3 全流程注入

**Given** 契约至少填写一项  
**When** 生成人物、三幕、分集、场次或分镜  
**Then** 对应 Prompt 包含已填写的契约字段和「持续兑现，不覆盖硬结构要求」说明

**Given** 场次生成请求  
**When** 服务端构造场次 Prompt  
**Then** 创作契约与其他步骤使用同一份项目上下文

### CC4 项目持久化与导出

**Given** 用户填写 V2 契约  
**When** 保存项目上下文、刷新页面或切换设备  
**Then** 七个字段完整恢复

**Given** 用户导入或导出项目包  
**When** 恢复项目  
**Then** V2 字段完整往返，缺失字段回落为空

### CC5 Agent 可读

**Given** 项目填写了 V2 契约  
**When** AI 场记读取项目状态或回答创作取舍  
**Then** 场记能看到故事承诺、追看回报和最终落点

### CC6 现有视觉不变

**Given** 当前 Signal Desk 工作台  
**When** 新增 V2 字段  
**Then** 继续复用现有 `BriefCard`、折叠容器、表单行和状态样式，不重做页面结构

## 4. UI 行为

- 入口仍称为「创作契约」，从原「创作意图」升级。
- 三个新增字段放在现有四个字段之前。
- 故事承诺可使用多行输入；追看回报和最终落点使用单行输入。
- 提供真实示例，不提供模型生成按钮。
- 未填写时明确说明：不填写时仍按原流程生成，但输出更接近类型平均值。
- 核心契约已就绪时只显示状态，不用分数或伪评分。
- 手机端字段单列，不出现横向滚动。

## 5. 非目标

- 不增加新的数据库表。
- 不让契约强制阻止生成。
- 不强制用户填满七个字段。
- 不在本阶段实现「A/B 带理由」「AI 味检测」「漂移检测」。
- 不修改当前主题、导航和页面骨架。

## 6. 测试清单

1. 旧四字段 JSON 可读取，新字段为空。
2. 七字段归一化、长度限制和签名稳定。
3. 空契约不产生 Prompt 片段。
4. 部分契约只输出已填写字段。
5. 人物、三幕、分集、场次、分镜五类 Prompt 均包含契约。
6. 项目上下文保存、读取、导出和导入完整往返。
7. Agent 项目状态包含新增字段。
8. 页面包含七字段标签和核心契约状态。
9. 现有全量测试与生产构建通过。
