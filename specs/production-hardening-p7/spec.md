# Production Hardening P7

> 本轮为批量外部视频增加手动镜头映射，解决无规则文件名无法自动匹配的问题。

## R1 手动映射

Given 批量预览中的文件无法从文件名识别
When 用户为文件选择一个项目镜头
Then 文件进入可导入列表
And 手动选择优先于文件名自动解析
And 原有自动匹配结果不受影响

## R2 冲突与无效项

- 两个文件映射到同一镜头时仍视为冲突，不允许提交。
- 非 MP4、空文件、超过 80MB 的文件即使手动选择镜头也不能提交。
- 选项中只允许当前项目真实镜头。
- 用户取消预览时不保留映射，也不上传任何文件。

## R3 界面

- 每个文件在预览中都有明确的镜头选择器。
- 自动匹配成功时预选对应镜头。
- 未匹配时显示“选择镜头”。
- 冲突原因和可导入数量实时更新。
- 桌面弹层与 390px 底部弹层均无横向溢出。

## 浏览器验收

- E2E 选择一个自动命名文件和一个无规则文件。
- 无规则文件手动选择到第 3 集第 2 镜。
- 预览数量从 1 个可导入更新为 2 个可导入。
- 确认后两个文件均进入镜头视频候选。

## 非目标

- 不提供拖拽排序或时间线内直接落位。
- 不支持一个文件映射多个镜头。
- 不改变服务端批量 mapping 协议。
