# 原生 App · 隐私可控分析

## 1. 目标

采集崩溃、关键性能、页面与核心转化事件，并由用户控制是否启用。

## 2. 边界

- 默认关闭匿名分析。
- 不采集提示词、剧本正文、图片、Token、邮箱或设备广告标识。
- 事件只包含名称、时间、页面路径和白名单属性。
- 分析失败不能阻断主流程。

## 3. 场景

- 用户在我的页显式开启或关闭。
- 开启后记录启动耗时、页面访问和关键转化。
- 错误边界记录崩溃摘要，不包含用户正文。
- 关闭后停止发送并清除待发送队列。

## 4. 验收

- 事件清洗、白名单、批量提交和用户开关有测试。
- 服务端按 owner 隔离并可注销账号时删除。
