# 集 / 场 / 镜画布生产地图

## 目标

保留现有六步流程画布，同时增加制作视角：以集为入口、场次为分区、镜头为可操作单元，把真实生产状态、缺口和已采用关键帧放到同一张画布上。

## 能力点

### PM1 · 双视图

- 画布顶部提供“制作地图 / 六步流程”切换。
- 制作地图优先展示当前项目真实分镜；没有分镜时提供进入工作台生成或切回流程的明确入口。
- 切换视图不修改项目内容。

### PM2 · 集场镜分组

- 镜头按集分组，未标集的镜头置顶且明确标记。
- 每集内按场次分组；有场次资料时使用其标题与概要，没有对应场次时建立“未标场次”分组。
- 同一集、同一场次内保持原始镜头顺序。

### PM3 · 真实生产信息

- 镜头卡显示镜号、场次、景别/运镜、时长、缺图或返修状态。
- 已采用镜头关键帧显示真实图片；没有采用图时显示“待出图”，不使用伪造缩略图。
- 点击镜头可直接定位到工作台对应分镜。

### PM4 · 规模与响应式

- 集用页签切换，避免一次铺开所有集的全部镜头。
- 镜头在场景内自动换行，不产生页面级横向滚动。
- 390px 下集页签可横向滚动但页面本身不溢出，主要按钮触控目标不小于 44px。
- 保留现有石墨底、发丝线和状态色，不新增视觉语言。

## 非目标

- 不在画布内直接生成视频。
- 不改变镜头数据结构、生成接口或导出格式。
