# 右侧舱镜头预览

## 目标

右侧舱的“产出”只在确有镜头可预览时出现，并明确命名为“镜头预览”。没有镜头的前五步只保留 Veya Agent，不再展示空壳页签或第二个 AI 提问入口。

## 能力点

### DO1 · 条件展示

- 当前步骤不是分镜或没有当前镜头时，不渲染“镜头预览”页签和面板。
- 进入分镜并存在当前镜头时，展示“镜头预览 / Veya Agent / 镜头属性”。
- 离开分镜后自动回到 Veya Agent，不残留不可见的面板状态。

### DO2 · 命名一致

- 原“产出”改名为“镜头预览”。
- Agent 页签使用完整名称“Veya Agent”，与舱内身份一致。

### DO3 · 预览有实际内容

- 预览显示镜头缩略图、镜号、场次、景别、画幅、时长、状态、动作和台词摘要。
- 预览不提供第二个 AI 提问框，避免与 Veya Agent 重复。

### DO4 · 响应式

- 390px 下页签与预览内容不重叠、不横向溢出。
- 页签触控目标不小于 44px。

## 非目标

- 不删除 Veya Agent。
- 不改变镜头属性编辑能力。
