# 视频模型选择与单镜重试

## 目标

让用户在镜头视频和批量视频中使用服务端真实可用的模型、分辨率和价格，不再由组件硬编码。模型能力必须可查询、可选择、可校验，并保留候选、预算和版本边界。

## 能力点

### VM-1 视频能力接口

- Web 端通过独立接口读取视频是否启用、默认模型、默认分辨率、可选模型、分辨率和每秒价格。
- 接口不得返回任何供应商密钥。
- 未启用视频时，生成入口禁用并说明原因。

### VM-2 镜头视频设置

- 单镜面板必须展示模型和分辨率选择。
- 预计金额和创作额度按所选模型、分辨率和时长实时计算。
- 自动采用服务端默认模型；用户切换模型时自动选择兼容分辨率。
- 镜头时长不在模型支持范围内时禁止提交。

### VM-3 批量视频设置

- 批量面板使用同一套模型能力、价格和时长校验。
- 不支持当前镜头时长的镜头必须进入阻断列表，不提交给供应商。
- 批次预算、模型和分辨率必须来自用户当前选择。

### VM-4 单镜失败重试

- 最新任务失败或取消时，单镜面板提供重试入口。
- 重试复用服务端任务记录和幂等规则，不覆盖旧任务、候选或采用版本。
- 重试成功后刷新任务和候选状态。

### VM-5 成本可见

- 单镜任务显示预计费用和已结算费用。
- 批量任务继续显示批次预留与实付费用。

## 非目标

- 本轮不接入 MiniMax 之外的供应商。
- 本轮不增加自动质量评分或自动路由。
- 本轮不移除现有服务端默认模型环境变量。
