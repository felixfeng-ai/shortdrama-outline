# 原生 App · 相机、相册与语音

## 1. 目标

Agent 输入区支持拍摄、选择参考图和中文语音转写，减少移动端长文本输入成本。

## 2. 边界

- 图片只在本机预览，当前不声称上传或让模型理解图片。
- 相机与相册权限由用户操作触发，不在页面打开时自动请求。
- 语音只把识别文本写入可编辑输入框，不直接发送。
- 权限拒绝、设备不支持或识别失败必须显示可读错误。

## 3. 场景

- 点击附件后选择“拍照”或“从相册选择”。
- 成功选择后显示缩略图、文件名与本机标记，可删除。
- 点击麦克风请求权限并开始中文识别；再次点击停止。
- 中间识别结果实时更新输入框，最终结果仍可手改。

## 4. 验收

- 图片结果解析与语音文本合并有单元测试。
- 输入区相机、相册、语音和停止路径有接线测试。
- 触控目标不小于 44，错误不只靠颜色表达。
