# 原生 App · 真实生成任务

## 1. 目标

任务页读取当前项目真实的 `generation_tasks`，不再展示静态演示队列。App 与 Web 共用同一任务状态、目标、错误和更新时间。

## 2. 硬边界

- 数据源只使用当前项目的 `generation_tasks`。
- 不新增 App 专属任务表，不复制任务正文。
- 任务状态只接受 `queued`、`running`、`succeeded`、`failed`、`canceled`。
- 本项不实现审片资产比较和重试写入；它们分别属于后续审片与失败恢复项。
- 项目切换后只显示新项目任务，旧请求不能覆盖新项目。

## 3. 能力与场景

### T1 真实任务读取

Given 当前项目存在生成任务
When 打开任务页
Then 按创建时间倒序显示真实任务、目标标签、状态、创建时间和失败原因。

### T2 状态筛选

Given 项目同时存在等待、运行、成功、失败和停止任务
When 用户切换筛选
Then 只显示对应状态，并显示真实数量。

### T3 状态与时间

Given 任务处于任意合法状态
Then 页面使用统一中文状态文案；已经结束的任务显示耗时，未知时间不伪造。

### T4 加载、空和失败

Given 工作区正在同步
Then 保留旧任务并标明同步中。

Given 当前项目没有任务
Then 显示可执行的任务空态，不展示演示任务。

Given 任务同步失败
Then 显示可读错误和重新同步入口。

### T5 项目隔离

Given 用户从项目 A 切换到项目 B
When 任务页刷新
Then 只显示项目 B 的任务；项目 A 的迟到响应不能覆盖页面。

## 4. 验收

- 移动上下文返回真实任务及真实目标标签。
- App 任务状态映射、筛选、计数、时间与错误脱敏有单元测试。
- 任务页 390/375 覆盖加载、空、失败、密集列表状态，无横向溢出。
- 移动端与 Web 全量测试、类型检查通过。
