# 项目画布巡检优化

## 目标

把项目画布从静态六步总览升级为项目巡检入口。用户打开画布后应先看见最需要处理的具体问题，再通过节点关系理解项目全貌；从问题可直接定位到工作台中的对应工件。

## P0 能力点

### C1 · 问题优先队列

- 画布顶部提供“优先处理”区域，最多展示 6 个具体问题。
- 生成失败任务优先于内容缺口；内容缺口优先于普通运行态。
- 每个问题包含节点名、具体对象、原因和定位动作。
- 无阻断问题时显示简短的通过状态，不占用大面积版面。
- 原有节点画布、搜索、分页、版本与内联编辑能力保留。

### C2 · 精确跳转

- 问题项可定位到具体角色、集、场、地点或镜头，而不是只打开步骤顶部。
- 镜头定位同步选中右侧镜头检查器。
- 跳转后目标工件滚入可见区域并获得焦点。
- 找不到目标时仍打开对应步骤，并给出可理解提示。

### C3 · 生成任务状态覆盖

- 打开画布时读取当前项目生成任务，并监听生成更新事件。
- 人物、地点、镜头生成中的数量显示在对应节点。
- 失败任务显示在节点和优先处理队列中。
- 任务汇总不复制任务中心的重试操作；用户定位到目标后再处理。

## 验收场景

### Scenario C1

**Given** 项目同时存在生成失败任务、缺参考图镜头和正常内容

**When** 用户打开项目画布

**Then** 优先处理队列先显示失败任务，再显示具体缺图镜头。

### Scenario C2

**Given** 优先处理队列显示第 8 集第 3 镜

**When** 用户点击定位

**Then** 工作台进入分镜步骤、选中第 3 镜、滚动到对应镜头卡，并把焦点交给该卡。

### Scenario C3

**Given** 人物和地点生成任务正在运行

**When** 用户查看画布

**Then** 视觉定妆节点显示人物任务数，地点锚点节点显示地点任务数，优先处理队列不把它们误报为失败。

## 不在本期

- 无限画布、节点自由摆放或连线编辑。
- 自动修复问题和自动重新生成。
- 多项目画布。
