# 成剧使用教程

## 目标

首次访问的创作者需要在五分钟内理解平台能做什么、完整生产链路怎么走，以及每个关键入口在哪里。

教程是工作型文档，不是营销落地页。结构采用 Flova 文档式的左侧章节、中间正文、右侧目录，但视觉沿用 Signal Desk。

## 入口

### Requirement

工作台和创作技能页必须提供明确的“教程”入口。

### Scenario T1

Given 用户位于工作台或创作技能页
When 寻找使用方法
Then 能看到文字为“教程”的入口，并可进入 `/docs`

## 快速开始

### Scenario T2

Given 用户第一次来到平台
When 打开教程
Then 首先看到“平台是什么”和“从想法到成片”的完整流程，而不是功能罗列

### Scenario T3

Given 用户已有小说、剧本或一句想法
Then 教程说明两种起点分别如何进入项目

## 六步生产

### Scenario T4

教程必须依次解释：

1. 核心人物
2. 三幕大纲
3. 分集
4. 视觉定妆
5. 场次
6. 分镜

### Scenario T5

教程必须说明第 6 步的三个工作区：分镜、镜头视频、时间线成片。

### Scenario T6

教程必须说明平台内视频要求已采用首帧，并支持外部即梦、可灵、剪映交付。

## 成片与导出

### Scenario T7

教程必须说明 TTS、BGM、SRT、MP4 和 manifest 的作用。

### Scenario T8

教程必须区分“外部平台生成”和“平台内成片”两条路径。

## Agent 与创作技能

### Scenario T9

教程说明 Agent 能读取项目、提出待确认卡，但不能绕过确认直接改库或创建付费任务。

### Scenario T10

教程说明创作技能是可复用方法，不是自动替用户做决定的黑盒。

## 界面

- 桌面为左侧章节、中间正文、右侧本页目录。
- 手机隐藏右侧目录，章节导航变成页首折叠入口。
- 正文行宽受控，长中文不横向溢出。
- 主行动是“开始第一次创作”，返回工作台。
- 首次创作、视觉定妆、镜头视频、时间线和导出五个关键节点必须配真实产品界面截图。
- 截图必须配可读的操作标注，并提供原图入口；不能只放无解释的界面图。
