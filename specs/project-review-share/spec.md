# 项目只读审阅链接

> 目标：编剧把当前项目文本产物发给导演、制片或客户审阅，不需要对方登录，也不能让对方修改项目。

## 能力

- 项目所有者生成 7 天有效的审阅链接；服务端只保存 token 哈希。
- 每次重新生成会撤销该项目之前仍有效的审阅链接。
- 链接只开放六步文本快照：想法、人物、三幕、分集、视觉定妆、场次、地点、分镜。
- 不开放本地参考图像素、云生成文件地址、额度、任务、账号或项目写接口。
- 审阅页明确标识「只读」，按六步顺序展示最新版产物，支持桌面与手机阅读。
- 链接过期、撤销或 token 非法时显示明确失效状态，不泄露项目内容。

## 场景

### S1 生成审阅链接

**Given** 用户拥有一个已保存项目

**When** 用户点击「生成审阅链接」

**Then** 创建新的只读 token，撤销旧链接，并把完整审阅 URL 复制到剪贴板。

### S2 打开审阅页

**Given** 审阅链接有效

**When** 未登录用户打开链接

**Then** 页面展示项目标题、最近更新时间、有效期与六步文本产物，不显示编辑控件。

### S3 失效链接

**Given** token 已过期、已撤销或不存在

**When** 用户打开链接

**Then** API 返回统一的不可用状态，页面只显示失效说明和返回成剧入口。

## 验收

- token 只存哈希，重新生成与过期行为有单元/API 测试。
- 审阅数据不包含 ownerId、本地图库 key、生成文件路径或写接口。
- 项目所有者校验、公开读取和失效状态均有测试。
- 桌面与手机页面无横向溢出、无控制台错误。
