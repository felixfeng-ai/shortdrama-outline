# 原生 App · 账号、数据与设备

## 1. 目标

用户可查看和下线其他设备、导出账号数据、注销账号；App 与 Web 共用同一用户和项目数据。

## 2. 边界

- 只有登录用户可导出或注销。
- 导出只包含结构化 JSON 和资产元数据，不打包原始像素。
- 注销必须二次确认，并删除项目、快照、任务、生成图片、推送 Token 和全部会话。
- 匿名用户可以查看当前匿名说明，但不能调用账号注销。

## 3. 场景

- “已登录设备”显示设备名、最后活动、当前设备与过期时间。
- 用户可下线非当前或其他设备。
- “导出我的数据”下载 JSON 文件。
- 用户确认注销后回到匿名会话，旧 Token 全部失效。

## 4. 验收

- 导出内容、归属隔离和注销级联有服务端测试。
- App 会话列表、下线、导出、注销请求有单元测试。
- 390/375 页面无横向溢出，破坏性操作有明确确认。
