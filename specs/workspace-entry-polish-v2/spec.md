# Workspace Entry Polish V2

## 目标

恢复正式工作区的高频入口，并收紧画布、下载和 Agent 浮标的行为。不改变工作台的信息架构。

## 能力点

### R1: 教程入口常驻

- 左侧工作区菜单提供“使用教程”入口，链接到 `/docs`。
- 更多菜单继续保留“使用教程”，作为移动端备用入口。

### R2: 手机 App 下载二维码

- 使用用户提供的二维码原图，不重新生成。
- 顶栏提供“下载手机 App”入口；点击打开二维码弹层。
- 弹层说明扫码下载、登录后跨设备继续同一项目。
- 二维码在桌面和 390px 手机宽度下完整可读，不拉伸变形。

### R3: 画布新窗口打开

- 现有顶栏“画布”、侧栏和首页“编排画布”继续在当前工作面打开。
- 画布页头额外提供一个“在新窗口打开”入口。
- 新窗口进入独立 `/canvas` 全屏画布路由，保留项目、步骤和项目标题。
- 新窗口不允许访问 `window.opener`。

### R4: 页脚品牌

- 页脚只显示“内测版”，不再显示“香港服务器”。

### R5: Agent 浮标

- 创作页的“问场记”从横向文字胶囊改为圆形图标按钮。
- 只保留图标、在线点与可访问名称，不再展示“选技能、查项目或直接开工”常驻文案。
- 按钮至少 `52px`，移动端不遮挡主要操作。

## 验收

- 源码测试覆盖教程入口、二维码资产与弹层、画布 `window.open`、页脚文案和 Agent 图标形态。
- Playwright 验证二维码弹层、画布新窗口 URL、390px 无横向溢出。
- 全量测试、类型检查和生产构建通过。
