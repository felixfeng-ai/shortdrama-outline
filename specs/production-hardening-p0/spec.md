# Production Hardening P0

> 本轮只处理真实用户已经能复现的生产级缺陷，不新增漫剧功能。

## R1 移动工作舱关闭态不占位

Given 390px 项目总览且工作舱处于收起状态
When 页面完成首次加载并等待 15 秒
Then 页面不得出现“正在载入工作模块”
And 工作舱 body 不参与布局、不遮挡正文
And 点击抓手后 Agent 正常展开，关闭后回到仅抓手状态
And 再次展开时原有对话和滚动位置仍在

## R2 示例入口直达完整示例

Given 新用户处于无项目起始页
When 点击“查看完整示例”
Then 页面进入示例项目总览，不进入创作技能页
And URL 只保留项目参数，不残留 `new=1` 或 `view=create`
And 示例项目至少包含一条可播放的示例成片
And 示例视频的尺寸、时长、SRT 终点与 manifest 声明一致
And 示例载入幂等、不调用模型、不扣额度

## R3 产品定位与当前范围一致

Given 漫剧当前只作为后续规划
Then 首页、登录页、公告、metadata、PWA 和品牌规范中的用户可见定位只能是 AI 短剧生产平台
And 漫剧仅保留在规划文档和内部路线图中

## R4 核心用户路径可自动验收

Given 隔离 SQLite 和本地媒体目录
When 执行核心 E2E
Then 浏览器从无项目进入示例总览
And 能看到并播放示例成片
And 能看到交付中心或交付包入口
And 桌面 1440 与移动 390 均无横向溢出和控制台错误

## 非目标

- 不接入真实付费视频供应商作为 CI 依赖。
- 不新增漫剧页面或分格产物。
- 不重做工作台视觉方向。
- 不在本轮处理跨供应商路由和自动发布。

## 验收

- 每个需求先有失败测试。
- 更新相关静态和单元测试。
- 真实浏览器完成无项目到示例总览路径。
- `npm test`、`npx tsc --noEmit`、`npm run build` 通过。
