# 原生 App · 推送权限与深链

## 1. 目标

用户主动开启通知后，App 注册 Expo Push Token；生成结束时由服务端向该设备发送通知，点击后直接进入对应任务或审片。

## 2. 边界

- 不自动请求通知权限。
- 模拟器、未配置 EAS Project ID、用户拒绝权限时显示真实状态。
- 通知 Token 按 owner 隔离，退出登录或注销账号时撤销。
- 服务端只接受 Expo Push Token，不保存推送正文。
- APNs/FCM 真机送达依赖 EAS 项目、开发构建和商店凭证，本机不能伪造验证。

## 3. 场景

- 用户在“我的”点击开启通知，授权成功后注册 Token。
- 权限拒绝、模拟器、缺少 EAS 项目或网络失败时显示可恢复说明。
- 生成成功/失败通知携带 `projectId / targetType / targetId / assetId`。
- 用户点击通知后，成功资产进入审片，否则进入任务页。
- 用户关闭通知时删除当前设备 Token。

## 4. 验收

- Token 校验、幂等保存、按 owner 隔离与删除有测试。
- App 注册请求、点击路由解析、UI 授权入口有测试。
- 通知插件和 Android 权限配置进入 app.json。
- 真机未验证项明确列出。
