# 原生 App · 工作区上下文同步

## 1. 目标

让原生 App 的 Agent 首页读取当前匿名会话下的真实项目上下文，包括项目标题、集数、场次、镜头数与额度。同步失败时保留本地草稿，不阻塞创作输入，也不伪造远端状态。

本轮只读，不调用模型、不扣额度、不修改项目。

## 2. 硬边界

- 继续使用现有暖白原生设计，不重排 Agent 首页。
- 原生 App 不依赖 WebView 或 Web 工作台。
- 只允许配置过的来源跨域访问 API，并允许携带匿名会话 Cookie。
- API 返回结构必须稳定，移动端不解析数据库内部格式。
- 同步失败保留最后一份可用数据，并显示明确恢复入口。
- 无项目时显示真实空态，不回填虚构项目。

## 3. 能力与场景

### R1 移动端上下文接口

Given 匿名会话下已有项目
When 原生客户端请求 `GET /api/mobile/context`
Then 返回项目列表、当前项目的集/场/镜头摘要、六步进度和额度。

并且接口只读，不触发 Agent、生成任务或额度扣减。

### R2 跨域与会话

Given 开发环境的 Expo Web 预览运行在 localhost 或 127.0.0.1 的任意端口
When 浏览器发起带凭据的 API 请求和预检
Then 服务端返回匹配的 `Access-Control-Allow-Origin`、凭据许可与允许的方法。

并且生产环境只接受 `CHENGJU_ALLOWED_ORIGINS` 明确列出的来源。

### R3 客户端同步

Given `EXPO_PUBLIC_API_URL` 已配置且接口可用
When Agent 首页加载
Then 客户端替换为远端项目标题、场次上下文和额度。

Given 请求失败或超时
Then 保留本地演示数据，状态显示同步失败，并提供重试。

Given 未配置接口地址
Then 明确进入本地草稿状态，不发起网络请求。

### R4 首页展示

Given 远端项目已有分镜
When 同步完成
Then 首页项目胶囊、当前集/场、场景标题和 AI 场记上下文使用远端数据。

### R5 空工作区

Given 当前会话没有任何项目
When 同步完成
Then 首页显示创建或导入项目入口，不展示虚构场次。
