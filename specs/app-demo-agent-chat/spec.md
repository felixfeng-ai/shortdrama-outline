# App Demo 真实 Agent 对话规格

## 能力点

### R1 · 项目上下文

- 对话使用当前项目标题、分集和分镜构建 AgentState。
- 已生成的步骤要标记为完成，未加载的步骤保持未完成。
- 工具读取的镜头状态、台词和场景来自当前项目快照。

### R2 · 真实 Agent 循环

- 发送后调用现有 `/api/agent`，并使用 `runAgentLoop` 执行只读工具。
- 工具执行过程在思考态可见，回答完成后保留简短的“已读”轨迹。
- Agent 提议修改时不直接改数据，提示用户去完整工作台确认。

### R3 · 失败与停止

- 网络、额度或模型错误显示在对话中，并给出重试方向。
- 停止按钮会中断正在进行的请求，不留下“永远思考”的状态。
- 发送期间禁止重复提交。

## 验收场景

- Given 项目有 3 个镜头，When 用户问项目状态，Then Agent 先读项目状态再回答。
- Given Agent 返回文本，Then 对话显示真实回答，不显示固定示例回复。
- Given 请求失败，Then 对话出现错误说明，输入框恢复可发送。
- Given 用户点击停止，Then 请求中断且思考态结束。
