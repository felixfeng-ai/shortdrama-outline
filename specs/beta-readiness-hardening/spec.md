# 内测上线准入硬化

## 目标

把当前可演示版本收紧为可以邀请首批真实创作者使用的内测版本。处理顺序固定为：运行时安全、Skill 承诺一致性、原文生产链、备份恢复、账号与接口防护、首批可见性与合规、完整回归与发布。

## P0 能力点

### B1 · 运行时安全

- 生产依赖不得存在 critical 或 high 漏洞。
- Next.js 升级后，构建、测试、PWA、API 路由与项目深链保持可用。
- 增加基础安全响应头或等价网关配置。

### B2 · Skill 承诺一致

- 标注“纯计算 / 0 模型调用”的 Skill 必须走确定性 Runner。
- 未实现确定性执行的 Skill 不得继续展示 0 模型调用承诺。
- 每个 Skill 在发送前明确输入、产物、额度和写入边界。

### B3 · 原文生产链

- 项目原文不能只停留在 Agent 摘录层，必须支持章节/段落定位与分批读取。
- 原文解析结果可进入原著圣经、人物、场次候选，并在写入前确认。
- 长文不得静默截断后仍宣称“已完整读取”。

### B4 · 备份与恢复

- 完整备份和项目包导入必须包含项目原文。
- 服务端导出清单与客户端完整备份必须使用同一项目设置口径。
- Nginx 对项目导入和原文写入的请求体限制必须覆盖应用层允许大小。

### B5 · 账号与接口防护

- 邮箱登录在生产域名可用；未配置时不得误认为可登录。
- 项目原文接口有写入限流、数量限制和按需读取，不一次返回全部全文。
- CI 在部署前执行测试、类型检查和依赖审计；生产部署后做健康检查。

### B6 · 内测可见性

- 没有项目时，原文入口不可误用，并提供创建项目路径。
- 空输入不能触发无效发送。
- 关键正文达到可读字号；移动端工具按钮保留可发现的名称。
- Agent 抽屉具备对话框语义、焦点陷阱和关闭后焦点恢复。

### B7 · 合规最低线

- 生成图片带 AI 生成标识或可审计来源说明。
- 内测页提供隐私、服务条款、内容规则与举报入口。
- 用户提交原文前明确说明原文会保存到当前项目。

## 验收场景

### Scenario B1

**Given** 安装锁文件中的生产依赖
**When** 执行生产依赖安全审计
**Then** critical 与 high 漏洞数量均为 0，测试和构建通过。

### Scenario B2

**Given** 用户选择“平台交付预检”
**When** 发送任务
**Then** 不调用模型，由确定性规则返回检查结果和 0 额度消耗。

### Scenario B3

**Given** 用户加入一份超过 12,000 字的剧本
**When** 要求改编
**Then** 系统按章节分批读取，报告覆盖范围，不把截断内容说成完整读取。

### Scenario B4

**Given** 项目包含原文、参考图和候选图
**When** 导出完整备份并重新导入
**Then** 原文、项目设置、快照和采用图都恢复；生产网关允许该文件大小通过。

### Scenario B5

**Given** 匿名会话反复写入项目原文
**When** 超过接口窗口上限
**Then** 返回 429 与 Retry-After。

### Scenario B6

**Given** 新用户没有任何项目
**When** 打开 Skill 页
**Then** 页面提供创建项目入口，原文入口在项目存在前不可误触。

## 不在本轮

- 原生 iOS / Android 客户端。
- 付费订阅、团队协作和成片时间线。
- 完整法律文本的最终审定；本轮只提供产品入口和最低限度说明。
