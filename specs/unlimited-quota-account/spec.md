# 无限额度管理账号

## 目标

提供一个受控的内部管理账号，用于跑通完整短剧生产链路，不受平台每日创作额度、全站熔断和短时 API 限流阻止。

## 安全边界

- 白名单只从服务端环境变量 `UNLIMITED_QUOTA_ACCOUNTS` 读取，不接受客户端传入。
- 支持按邮箱、手机号、用户名或用户 ID 匹配。
- 未命中的普通账号规则完全不变。
- 管理账号仍记录 usage_log 和 reservation，便于核对真实消耗。
- 上游模型供应商自己的限流、余额和鉴权仍照常生效。

## 场景

### 额度查询

给定当前账号命中无限额度白名单  
当查询 `/api/quota` 时  
则返回 `unlimited: true`，界面展示“管理账号 · 无限额度”。

### 额度预扣

给定管理账号单次或累计生成超过普通日额度  
当创建额度预扣时  
则跳过账号额度和全站熔断校验，但仍写入预扣与用量记录。

### API 限流

给定管理账号命中短时图像、视频、文本等限流  
当调用生成接口时  
则不递增也不阻塞该账号的限流桶。

### 普通账号隔离

给定账号不在白名单  
当生成时  
则继续使用现有额度和限流规则。

## 验收

- 环境变量为空时功能完全关闭。
- 白名单支持多账号，使用逗号或分号分隔。
- 生产管理账号固定为 `felix@chenju.work`，通过部署环境变量 `UNLIMITED_QUOTA_ACCOUNTS` 注入。
- 前端额度条、批量生图面板和 Agent 额度工具识别无限额度状态。
- 单元测试覆盖身份匹配、超额预扣、限流绕过和普通账号不受影响。
