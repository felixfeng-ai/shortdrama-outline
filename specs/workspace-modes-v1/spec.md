# Workspace Modes V1

> 用户于 2026-11-06 确认方向一：首页工作台保留，顶部使用「总览 / 创作 / 画布」三种模式。

## 目标

在现有正式工作台中引入三种同层工作模式，不新增独立路由页面，不复制技能库和编排画布的实现。

## 能力点

### R1: 三模式 URL 状态

- `view` 缺省或为 `overview` 时显示现有总览工作台。
- `view=create` 时显示创作模式。
- `view=canvas` 时显示画布模式。
- 模式切换必须保留 `project` 与 `step` 参数，并支持刷新、前进与后退。

#### Scenario: 从总览进入创作

- Given 当前 URL 含项目和步骤，且没有 `view`
- When 用户选择「创作」
- Then URL 增加 `view=create`
- And 项目与步骤参数保持不变

#### Scenario: 从创作进入画布

- Given 当前 URL 为 `view=create`
- When 用户选择「画布」
- Then URL 的 `view` 变为 `canvas`
- And 不会新增第二个模式参数

### R2: 总览保持原工作台

- 总览模式继续渲染现有的项目条、当前任务、六步导航、故事输入、步骤内容和最近产物。
- 不因新增模式删除或替换现有创作能力。

### R3: 创作复用现有技能库

- 创作模式复用 `SkillCatalog`，不创建第二套技能数据。
- 嵌入模式隐藏技能页自己的顶栏，保留技能分类、技能图片、搜索、推荐、执行计划和个人技能。

### R4: 画布复用现有编排画布

- 画布模式复用现有 `ProjectCanvas` / `CanvasGraphWorkspace`。
- 顶部「画布」入口默认进入「编排画布」视图。
- 保留节点拖拽、缩放、连线、节点编辑、自动保存、冲突提示和同浏览器多标签同步。

### R5: 公告

- 使用 `LATEST_PRODUCT_RELEASE` 作为唯一公告内容来源。
- 公告条只在总览和创作显示，进入画布时隐藏。
- 公告可展开、可关闭，并按版本记住关闭状态。

### R6: 响应式与可访问性

- 桌面、平板和手机均可切换三种模式。
- 模式控件使用可访问的 tab 语义，支持键盘焦点。
- 手机端不出现页面级横向滚动，画布模式不叠加外层底部导航。

## 验收

- 单元测试覆盖 URL 模式读写与兼容旧画布查询。
- Playwright 覆盖总览、创作、画布切换，技能分类/图片，真实画布交互，公告显示/关闭/隐藏。
- `npx tsc --noEmit` 通过。
- `design-taste inspect` 无 FAIL。
- `impeccable detect` 无 warning。

## 非目标

- 不重做六步生成链路。
- 不新建第二套画布或技能库。
- 不改变 Agent 写入确认、额度、Canon 或版本规则。
