# 原生 App · 分享、离线、平板与任务恢复

## 1. 分享

- 当前项目可生成 7 天只读审阅链接并调用系统分享。
- 重新生成会撤销旧链接，分享失败不伪造成功。

## 2. 离线最近项目

- 最近 5 个工作区快照保存在本机。
- 切换项目时先读取对应缓存，再尝试网络同步。
- 生成图片、Token 和正文不额外复制到缓存。

## 3. 平板与横屏

- iPad 与 Android 平板允许安装。
- 横竖屏都使用居中的最大宽度内容区，避免把信息拉成超宽工作台。

## 4. 跨页面任务恢复

- 全局任务桥在 App 回前台时刷新工作区。
- 存在 queued/running 任务时定时同步，离开页面后仍继续。
- 任务与项目共享同一 WorkspaceProvider。

## 5. 验收

- 分享 API、缓存选择、平板样式和全局恢复有单元测试。
- 390、1024 宽度截图无溢出；真机仍未验证。
