# Skill 可执行计划

## 目标

把 Skill 从“模板卡片 + 大输入框”升级为可审阅的执行计划。用户选择 Skill 后，先看到会读取什么、分几步执行、每步输入与产物、额度与时间、确认节点、失败恢复和产物形状，再决定是否交给 Agent。

## 能力点

### SP1 · 上下文推荐

- Given 当前项目已有分镜，Then 推荐连续性和交付相关 Skill。
- Given 只有原文，Then 优先推荐改编相关 Skill。
- 默认展示 3 个推荐，每项说明推荐理由与前置缺失，不自动执行。

### SP2 · 执行计划

- 选择 Skill 后展示可执行计划，包含项目上下文、3–4 个执行步骤、每步输入与产物。
- 计划必须显示额度上限、预计耗时、只读/写入边界、确认节点和中断恢复说明。
- 输出预览只描述真实产物结构，不伪造模型结果。

### SP3 · 执行边界

- 点击主操作只打开 Agent，不自动写入项目或生成图片。
- 前置缺失或额度不足时，主操作禁用并说明原因。
- 模型类 Skill 的 Agent 循环上限与计划中展示的额度上限一致。

### SP4 · 视觉与响应式

- 执行计划沿用 Signal Desk 石墨底、鼠尾草绿和冷蓝，不新增第二套视觉语言。
- 桌面采用“步骤主列 + 约束侧列”，390px 单列堆叠。
- 页面不得横向溢出，主要动作触控目标不小于 44px。

## 非目标

- 不新增 Skill 市场、计费系统或后台任务队列。
- 不在本页直接执行生成、写快照或改正文。
