# 原生 App · 弱网与长任务恢复

## 1. 目标

弱网时保留最后成功数据，幂等请求自动有限重试；回到前台后恢复任务同步。

## 2. 边界

- 自动重试只用于 GET 和明确幂等的请求。
- 写操作不自动重放，避免重复扣费或重复写入。
- 缓存只保存工作区摘要，不保存生成图片和敏感 Token。
- 超过重试次数后显示可操作错误。

## 3. 场景

- 工作区成功同步后保存最后快照。
- 下次启动先显示缓存，再用网络结果替换。
- GET 遇到网络错误按指数退避重试。
- App 从后台回到前台，任务页立即刷新。

## 4. 验收

- 重试次数、退避和不可重试状态有测试。
- 缓存读写、损坏容错和项目切换有测试。
