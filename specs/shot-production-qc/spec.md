# 镜头生产质检与批量返修

## 目标

把角色/地点锚点、禁改项、参考图和生成图版本问题直接显示在制作工作台的镜头卡上，并允许用户筛出问题镜头、确定性修复 Prompt 或批量标记返修。

## P0 能力点

### Q1 · 镜头级质检

- 每个镜头计算缺角色锚点、缺禁改项、缺参考图、参数不兼容和旧参考图。
- “旧参考图”只在该镜已采用生成图早于当前采用角色/地点图时报告，不能凭名称猜测。
- 没有生成图的镜头不报“旧参考图”。
- 镜头卡直接显示问题标签，右侧检查器显示具体原因。

### Q2 · 问题筛选

- 制作工作台提供“全部镜头 / 仅看问题”切换。
- 筛选后集场镜树、卡流和批量生成范围保持同一口径。
- 没有问题时显示明确的通过状态，不占用大块空间。

### Q3 · 确定性修复

- “修复提示词”只把当前已采用角色/地点锚点补进 Prompt，不调用模型、不扣额度。
- 已采用生成图的镜头被修改 Prompt 后标记为“需返修”。
- “标记旧参考返修”只修改镜头状态，不自动生成图片。

### Q4 · 批量返修

- 问题筛选后的镜头可直接进入现有批量首帧生成面板。
- 批量生成仍复用任务中心、候选图、采用和恢复机制。
- 修复与标记操作必须报告影响镜头数。

## 验收场景

### Scenario Q1

**Given** 某镜 Prompt 缺少当前角色锚点

**When** 打开制作工作台

**Then** 镜头卡显示“缺锚点”，检查器显示角色名。

### Scenario Q2

**Given** 角色采用图在该镜采用图之后生成

**When** 计算质检结果

**Then** 该镜显示“旧参考”，其他没有生成图或参考图更旧的镜头不误报。

### Scenario Q3

**Given** 用户点击“修复提示词”

**When** 修复完成

**Then** Prompt 包含当前锚点，额度不变；原来已出图的镜头进入需返修状态。

### Scenario Q4

**Given** 用户打开“仅看问题”

**When** 启动批量首帧生成

**Then** 只提交当前问题镜头，不提交其他正常镜头。

## 不在本期

- 自动重写剧情内容。
- 自动重生成图片且不确认成本。
- 跨项目角色库。
