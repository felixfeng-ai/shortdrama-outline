# 原生 App · Apple / Google 订阅

## 1. 目标

App 通过平台内购展示真实商品、发起购买、恢复购买，并把交易提交到服务端核验与记账。

## 2. 硬边界

- 不在 App 内引导用户到外部支付数字内容。
- 未配置商品 SKU、开发构建或商店账号时显示真实不可用状态。
- 客户端成功回调不等于已付款；只有服务端核验通过才能授予权益。
- 未接入 Apple/Google 收据核验服务时交易只能是 `pending`，不得增加额度。
- 原始凭据只提交服务端，不写入日志或界面。

## 3. 场景

- 我的页进入订阅页，服务端返回已配置的 SKU。
- 原生构建连接商店并展示本地化价格与周期。
- 用户购买后，交易幂等写入服务端；外部核验通过才标记 verified。
- 用户恢复购买时重新获取可用交易并提交核验。
- Web 预览、Expo Go 或未配置商店时明确说明限制。

## 4. 验收

- 商品配置、交易幂等、owner 隔离与 pending 状态有服务端测试。
- App 商品读取、交易提交、恢复与失败状态有测试。
- 本机不声称完成 App Store / Play 沙盒购买；需真机与商店凭证。
