# 原生 App · 真实生成资产审片

## 1. 目标

任务页成功任务可进入原生审片页，读取当前项目真实的 `generated_assets`，完成版本切换、采用和下载。

## 2. 边界

- 只读取当前项目真实资产，不保留静态 `SceneFrame`、固定 V1/V2/V3 或虚构一致性分数。
- 采用继续调用既有 `PATCH /api/generations`。
- 图片继续使用 `/api/generated-assets/:id`，登录用户通过 Bearer 鉴权读取。
- 没有资产时显示真实空态，不伪造画面。
- 本项不臆造“退回重做”状态；未实现的审核决策不提供假按钮。

## 3. 能力与场景

### R1 任务入口

Given 任务已成功且带 `assetId`
When 用户点开任务
Then 进入对应目标的审片页。

Given 任务仍在运行或没有资产
Then 不提供审片入口。

### R2 版本读取

Given 目标存在多个生成资产
Then 按创建时间展示全部版本，并优先选中 URL 指定的资产或当前采用版本。

### R3 预览与元信息

Then 显示真实图片、模型、大小、创建时间、采用状态和 AI 标识，不显示未提供的质量分数。

### R4 采用

Given 用户查看未采用版本
When 点击采用
Then 调用既有接口并在页面同步选中状态。

Given 当前版本已采用
Then 按钮禁用并显示“当前采用”。

### R5 下载与状态

Given 用户点击下载
Then 通过鉴权请求获取当前图片并在 Web 下载或原生系统中保存/分享。

Given 加载失败或没有资产
Then 显示可恢复错误或空态。

## 4. 验收

- 审片 API、版本选择和任务入口有单元测试。
- 390/375 覆盖多版本、采用、空和错误状态。
- 图片有可读替代文本，按钮触控目标不小于 44。
- 移动端和 Web 全量测试、类型检查通过。
