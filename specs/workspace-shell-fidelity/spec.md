# Workspace Shell Fidelity V1

> 用户已确认：以 `design-previews/2026-11-05-veyaframe-final-compare/one-workspace.html`
> 为页面结构和视觉事实源，不再用通用设计评分改写确认稿。

## 目标

把正式工作台改成确认稿的工作区结构，同时保留现有项目数据、生成链路、Agent、导出和编辑交互。

## 能力点

### R1: 完整工作区侧栏

- 桌面侧栏固定 `232px`，顶部为六边形 V 标志、`VeyaTV` 和 `成剧`。
- 侧栏包含工作区切换器。
- `工作区` 分组顺序固定为：首页、我的项目、项目待办、创作技能、资产库。
- 当前项目步骤顺序固定为：当前步骤优先，其余按分镜、核心人物、三幕大纲、分集剧情、角色定妆、场次剧本。
- `项目工具` 分组顺序固定为：编排画布、产物中心、生产台账。
- 侧栏底部显示账号/登录入口、额度和保存状态。

### R2: 顶部与公告

- 主工作区顶部为面包屑 `我的项目 > 当前项目`。
- 顶栏右侧显示保存状态、导出交付包、更多工具和账号。
- 产品公告位于顶栏之后、模式条之前。
- 模式条顺序固定为：总览、创作、画布。

### R3: 总览首页

- 页面标题为 `继续创作`，副标题使用真实项目名、集数、类型和最后保存时间。
- 主操作是 `继续{当前步骤}`，次操作是 `编排画布`。
- 首屏主角是当前阻断/当前任务，不再显示故事输入框。
- 六步状态轨道使用真实完成态和当前步骤。
- 下方使用 `当前工作 + 项目脉搏/下一步/可调用创作方法` 双栏。
- 最近产物使用真实分集、定妆和分镜数据。

### R4: 创作与画布

- 创作模式仍在同一工作区内显示技能库、输入区、分类和执行计划。
- 画布模式在正式页面内直接渲染真实 `CanvasGraphWorkspace`，不再使用全屏对话框。
- 画布仍支持拖拽、缩放、连线、节点编辑、自动保存和多标签同步。

### R5: 移动端

- 手机侧栏通过菜单按钮打开为完整抽屉，内容顺序与桌面一致。
- 页面提供五项底部导航：首页、项目、待办、技能、我的。
- 页面本身不得横向滚动。

### R6: 视觉 token

- 页面底色 `#08090A`，侧栏 `#0A0B0C`，面板 `#101214`。
- 主文字 `#F0F2EF`，次文字 `#B0B5B5`，弱文字 `#868D90`。
- 主按钮 `#F2F2EE`，按钮文字 `#0D0E0F`。
- 运行、选中和连接线使用冷蓝 `#8DC8DC`。
- 不再使用 `#C4D98A` 鼠尾草绿作为新工作区主色。

### R7: 真实交互不退化

- 项目切换、重命名、新建、导入、导出继续走现有 handler。
- 项目待办、资产库、产物中心、生产台账入口必须打开现有真实功能。
- `继续分镜`、`处理阻断`、六步轨道继续使用现有步骤跳转。
- 空项目保留载入示例项目的入口。

## 验收

- 源码测试覆盖菜单分组顺序、焦点 token、公告顺序、移动抽屉和真实画布接线。
- 纯函数测试覆盖当前步骤优先排序、项目脉搏和当前镜头选择。
- Playwright 在 1440、768、390 验证菜单、三模式、公告和侧栏抽屉，并确认无控制台错误、无页面级横向溢出。
- `npx tsc --noEmit`、全量测试和生产构建通过。
- 不提交、不推送、不部署，先由用户本地确认。

## 非目标

- 不修改生成 API、数据表、计费、Canon 或 Agent 写入规则。
- 不重做六步编辑器内部表单。
- 不用通用设计规则替换确认稿的布局和菜单。
