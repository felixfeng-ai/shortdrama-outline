# App Demo 镜头轨道规格

## 能力点

### R1 · 真实镜头轨道

- 创作页展示当前项目最新 `shots` 快照中的镜头。
- 每个镜头显示镜号、场景、台词或动作摘要、状态。
- 轨道支持横向滚动和键盘选择，不把页面本身撑出横向滚动。

### R2 · 选中镜头联动

- 点击镜头后，工作台标题、动作说明、首帧标签和确认项同步更新。
- 选中镜头使用整块底色、全边框和字重强调，不使用左侧竖线。
- 进入创作页时自动把当前镜头滚到轨道中间。

### R3 · 空态与极端情况

- 项目没有分镜时，轨道显示“还没有分镜”并指回完整工作台。
- 长台词、长场景名和大量镜头不能撑破页面。
- reduced-motion 下轨道定位不使用平滑滚动。

## 验收场景

- Given 项目有一组镜头，When 进入创作页，Then 出现镜头轨道并选中第一镜。
- Given 用户点击第 2 镜，Then 标题、动作说明和首帧标签都切换为第 2 镜内容。
- Given 项目没有镜头，Then 显示镜头空态而不是空白轨道。
- Given 页面运行于 375px，Then 页面无横向滚动，轨道自身可横向滚动。
