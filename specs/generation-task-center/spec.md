# 项目生成任务中心

## 1. 目标

把项目内角色定妆图和镜头首帧的生成任务收在一个默认收起的面板里，支持状态总览、错误查看、单任务重试和批量重试。

## 2. 边界

- 本轮只管理图片关键帧任务，不接图生视频。
- 不自动重试，任何新 Provider 调用都必须由用户点击。
- 批量重试必须二次确认，并串行执行，避免并发放大成本。
- 任务中心只读取当前项目，不跨项目聚合。

## 3. 场景

### TC1 状态总览

**Scenario TC1.1**
Given 当前项目已有生成任务
When 用户打开项目
Then 显示一行任务摘要，包含运行、等待、成功、失败和取消数量。

**Scenario TC1.2**
Given 当前项目没有生成任务
Then 任务中心不渲染，不占用页面空间。

### TC2 任务明细

**Scenario TC2.1**
Given 用户展开任务中心
Then 每行显示目标名称、任务类型、状态、时间和可读错误。

**Scenario TC2.2**
Given 成功任务有对应关键帧
Then 显示缩略图和“已生成 / 已采用”状态。

### TC3 重试

**Scenario TC3.1**
Given 某目标的最新任务失败或被取消
When 用户点击“重试”
Then 使用原任务提示词创建新任务。

**Scenario TC3.2**
Given 多个目标的最新任务失败或被取消
When 用户点击“重试失败项”
Then 先进入确认态，确认后串行重试，不并发调用 Provider。

**Scenario TC3.3**
Given 某目标已有更新的成功或运行任务
When 计算可重试项
Then 不重试该目标的旧失败记录。

## 4. 验收

- 状态汇总、旧任务去重、目标标签和重试选择有单元测试。
- 面板响应式无溢出，按钮触控高度至少 36px，移动端 44px。
- 全量测试、类型检查、构建和浏览器验收通过。
