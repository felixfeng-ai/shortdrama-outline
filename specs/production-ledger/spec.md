# 团队批注与生产台账

> 状态：已实现，等待产品验收
> 日期：2026-11-04
> 优先级：P1，内测协作与交接

## 1. 目标

把分散在分镜状态、镜头质检、实体批注、生成任务和采用图中的制作信息，
汇总成一份逐镜可核对、可复制的生产台账。

本轮不新增团队角色、成员邀请或权限后台，只服务同一项目的交接和批注跟进。

## 2. 台账模型

每个镜头一行，包含：

- 集号、镜号、场景、镜头稳定 ID
- 镜头制作状态：待出图 / 已出图 / 需返修
- 画幅、时长、出场角色
- 质检问题数与问题摘要
- 未处理批注数、最新批注正文
- 最新生成任务状态与错误摘要
- 是否已有采用图、最近采用时间

顶部汇总：

- 总镜数、完成、返修、待出图
- 问题镜头数、缺图镜头数
- 未处理批注、失败或取消任务

## 3. 输出

- 台账 schema 固定为 `chengju.production-ledger`，版本 `1`。
- CSV 使用稳定中文表头，正文按标准 CSV 转义。
- JSON 包含 schema、generatedAt、summary、rows。
- 项目包固定新增：
  - `production/ledger.csv`
  - `production/ledger.json`
- 交付包和完整备份都包含当前台账。

## 4. UI

- 项目状态条新增“生产台账 N”，N 为镜头行数。
- 折叠面板先显示汇总，再列最多 20 行。
- 每行优先显示需返修、质检问题和未处理批注。
- 提供“复制台账 CSV”操作。
- 保留现有 Signal Desk 深色工作台，不新增全屏页面。
- 手机端单列，无横向溢出。

## 5. 批注

- 台账按镜头稳定 ID 匹配批注。
- 非镜头批注不进入逐镜行，但保留在实体批注面板。
- 作者只展示脱敏成员标识，不暴露会话 token 或完整 authorId。
- 已解决批注不计入未处理数，但可作为最近批注内容显示。

## 6. 非目标

- 不邀请成员、不分配角色、不建审批流。
- 不修改生成任务或批注状态。
- 不把台账当作财务结算单。
- 不读取本地图片像素。

## 7. 验收

1. 台账逐镜合并且不重复。
2. 批注、任务、质检和采用图匹配稳定 ID。
3. CSV 对逗号、引号和换行正确转义。
4. 项目包同时含 CSV 和 JSON 台账。
5. UI 可复制台账，桌面和手机无溢出。
6. 全量测试、TypeScript、生产构建通过。
