# 用户名与账户身份展示

## 背景

当前邮箱首次登录会把邮箱前缀拼成“用户 + 前缀”的显示名。该名称既可能暴露邮箱，也常常过长，导致工作区侧栏无法完整展示。

## 目标

- 用户名是工作区展示的账户主身份。
- 首次登录未设置用户名时自动生成短中文用户名。
- 用户可在账户页修改用户名。
- 邮箱和手机号仅用于登录、身份详情和找回项目，不作为工作区主标签。
- 不修改用户的邮箱、手机号、项目归属或登录方式。

## 规则

- 用户名长度为 2–16 个字符。
- 允许中英文、数字、下划线和短横线。
- 不允许空格、邮箱符号和其他特殊字符。
- 用户名不允许被其他账户占用。
- 旧版以“用户”开头的自动显示名视为未设置用户名，在读取会话或启动数据库时补成新用户名。
- 自动生成名不得包含邮箱、手机号或“用户”前缀。

## 场景

### 首次登录

给定用户首次通过邮箱登录，且尚未设置用户名  
当验证码验证成功时  
则系统生成短用户名并随会话返回。

### 修改用户名

给定用户已登录  
当提交合法且未占用的用户名时  
则用户名持久化，并在工作区和账户页同步展示。

### 用户名冲突

给定用户名已被其他账户使用  
当当前用户提交该用户名时  
则系统拒绝修改并返回明确错误。

### 长名称与邮箱隔离

给定用户名超长或历史显示名包含邮箱前缀  
则侧栏优先展示用户名并单行省略，邮箱只出现在账户详情中。

## 验收

- 账户接口支持读取和修改用户名。
- 新用户登录不再生成“用户 + 邮箱前缀”。
- 旧用户下一次读取会话时自动获得新用户名。
- 登录页可设置用户名，展示成功、失败和保存中状态。
- 桌面与手机侧栏无横向溢出，长用户名不推挤额度区。
