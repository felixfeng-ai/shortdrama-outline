# App Demo 共享 Web 数据规格

## 能力点

### R1 · 项目列表共享

- `/app-demo` 通过同源 `/api/projects` 读取当前浏览器会话的项目。
- 有 Web 项目时，优先展示真实项目；没有项目时，保留明确标记的视觉示例。
- 项目面板区分「Web 项目」和「界面示例」，不能把示例伪装成真实项目。

### R2 · 项目内容映射

- 选中 Web 项目后，读取该项目最新的 `episodes`、`scenes`、`shots` 快照。
- 首页标题、场次、台词、镜号、镜头数和工作台内容使用真实数据。
- 未生成分集、场次或分镜时，显示可执行的空态，不出现 `undefined` 或虚假镜号。

### R3 · 完整工作台入口

- 本机会话面板显示当前 Web 项目数量与连接状态。
- 提供「打开完整工作台」入口，并携带当前 Web 项目 id。
- 完整 Web/App 工作台读取 `project` 查询参数并打开指定项目。

### R4 · 失败恢复

- 项目接口失败时保留视觉示例，并显示重试入口。
- 空项目列表显示「从完整工作台新建项目」的下一步。

## 验收场景

- Given 当前 Cookie 下有 2 个项目，When 打开 `/app-demo`，Then 项目面板先展示这两个 Web 项目。
- Given 选中一个已有分镜的项目，Then 首页场次、镜号和镜头数与最新快照一致。
- Given Web 项目为空，Then 面板显示空态和进入完整工作台的入口。
- Given 项目接口失败，When 点击重试，Then 再次请求且不丢失当前示例内容。
- Given 点击「打开完整工作台」，Then URL 包含 `app=agent&project=<id>`。
