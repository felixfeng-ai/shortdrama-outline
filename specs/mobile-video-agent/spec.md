# App 视频任务、审片与 Agent 就绪度

## 目标

App 不变成移动版 Web 工作台。本轮只补齐视频生产闭环中最适合手机完成的部分：查看任务、审片、从已采用首帧发起单镜视频、控制预算，并让 Agent 知道当前哪些镜头缺首帧或视频。

## 能力点

### R1 统一媒体任务契约

- Mobile Context 的每个任务返回 `mediaKind`、`batchId`、预估成本和实际成本。
- 项目上下文返回视频能力、批次摘要、视频目标和视频就绪度。
- 视频能力只暴露模型、分辨率、时长和单价，不暴露 API Key。
- App 刷新时同步对账当前项目的视频任务。

### R2 任务中心识别图片与视频

- 用户可在全部、图片、视频之间筛选任务。
- 视频任务使用视频图标和媒体标签，不与图片任务混淆。
- 图片任务继续调用 `/api/generations`；视频任务调用 `/api/video/generations`。
- 批量视频任务显示批次状态和预算信息。

### R3 原生视频审片

- 审片页同时读取图片和视频任务，并按 `mediaKind` 分开版本列表。
- 视频使用原生播放器，不放进 WebView。
- 视频版本可切换、采用、下载 MP4。
- 推送成功进入视频审片时携带 `mediaKind=video`。

### R4 App 单镜视频生成

- 用户可从已采用镜头首帧发起视频生成。
- 生成前显示模型、分辨率、时长、单次费用和缺少首帧的阻断原因。
- 请求携带幂等键、预算上限和不自动采用的策略。
- 视频提交成功后进入任务页，不伪造已生成资产。
- 服务未配置、缺首帧或费用未知时禁用提交并说明原因。

### R5 Agent 视频就绪度

- Agent 状态包含镜头总数、已采用首帧数、已采用视频数、缺首帧数、缺视频数、进行中和失败任务数。
- `get_project_status` 回答视频生产状态，不创建付费任务。
- Agent 不自动生成、不自动采用、不自动重试。

## 验收

- Web/App 单元测试覆盖任务媒体筛选、视频审查、费用计算、Agent 就绪度和权限边界。
- 两端 TypeScript、Web 全量测试和 Next build、App 全量测试和 Expo export 通过。
- 390 和 375 视口截取任务、视频生成入口和视频审片页，无横向溢出。
- 真实视频 Provider 调用仍需在配置密钥后验证，代码测试不能替代供应商沙箱。
