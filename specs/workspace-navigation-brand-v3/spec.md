# Workspace Navigation & Brand V3

## 目标

把教程入口放回主菜单，提供真正的全屏画布窗口，并统一登录页与工作区的品牌标志。

## 能力点

### R1: 教程进入主菜单

- 左侧“工作区”菜单新增“使用教程”，链接到 `/docs`。
- 顶栏不再依赖单独教程图标；更多菜单继续保留教程备用入口。
- 教程内容补充“总览 / 创作 / 画布”、全屏画布、手机 App 和跨设备继续项目。

### R2: 全屏画布窗口

- 当前工作区内的“画布”主入口保持不变。
- 画布页头“在新窗口打开”进入独立 `/canvas` 路由。
- `/canvas` 不渲染工作区侧栏、模式条、产品公告和站点页脚，只渲染全屏 `CanvasGraphWorkspace`。
- URL 保留 `project`、`step` 与项目标题；无项目时显示可读空态。

### R3: 品牌统一

- 登录页、工作区侧栏和手机顶栏使用同一个六边形 V 品牌组件。
- 登录页品牌字为 `VeyaFrame` + `成剧`，不再使用白色方块字母 V。
- 登录页品牌字号、字重和间距与工作区侧栏一致。

### R4: 教程图片

- 教程截图更新为当前近黑工作区。
- 至少覆盖首页总览、创作模式、全屏画布、Agent、App 下载/跨端。
- 教程中的文字不得再描述已经下线的顶部工具或旧布局。

### R5: 内测公告

- 公告标题明确写“VeyaFrame 火热内测中”。
- 正文告诉用户平台正在内测，欢迎踊跃体验，并说明安卓、鸿蒙与 iOS 状态。
- 公告仍保持单行紧凑形态，可展开、可关闭并按版本记忆。

## 验收

- 源码测试覆盖菜单入口、全屏路由、共享品牌组件与教程新内容。
- Playwright 验证 `/canvas` 无工作区 chrome、项目与步骤保留。
- Playwright 验证登录页和首页品牌几何一致。
- 全量测试、类型检查和生产构建通过。
