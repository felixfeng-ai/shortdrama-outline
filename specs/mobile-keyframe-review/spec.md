# 手机端关键帧审片

## 1. 目标

让 App 用户在任务页直接完成关键帧巡视、版本比较、采用和下载，不必进入完整工作台寻找对应角色卡或镜头卡。

## 2. 边界

- 只使用当前项目已经生成的 `generated_assets`，不新增生成接口或第二套资产数据。
- 只展示当前匿名会话可访问的项目资产，权限继续由既有项目访问校验负责。
- 审片入口只出现在 App 外壳中；普通网页与桌面工作台沿用现有 `KeyframePanel`。
- 采用版本继续调用既有 `PATCH /api/generations`。
- 下载仍使用资产既有 `downloadUrl`，不复制图片或写入额外文件。
- 没有生成资产时整块审片区隐藏，不占任务页空间。

## 3. 能力与场景

### R1 审片分组

**Requirement**：生成资产按角色或镜头聚合成可巡视的审片组。

**Scenario R1.1**
Given 同一角色存在多个关键帧版本
When 构建审片列表
Then 它们属于同一组，按创建时间倒序排列，并显示角色名。

**Scenario R1.2**
Given 同一镜头存在多个首帧版本
Then 它们属于同一组，并显示镜号和场景。

**Scenario R1.3**
Given 资产引用的角色或镜头已不在当前产物中
Then 使用可读兜底名称，不崩溃、不隐藏该资产。

### R2 任务页入口

**Requirement**：任务页展示最近有资产的审片组。

**Scenario R2.1**
Given 当前项目存在已生成关键帧
When 打开任务页
Then 显示“待审关键帧”横向卡片、当前采用状态和版本数。

**Scenario R2.2**
Given 当前项目没有生成资产
Then 不显示审片区，任务中心行为保持不变。

### R3 版本比较

**Requirement**：审片层支持在多个版本之间比较。

**Scenario R3.1**
Given 用户点开一个审片组
Then 打开可关闭的全屏审片层，优先定位当前采用版本。

**Scenario R3.2**
Given 该组有多个版本
When 用户点击缩略图或左右滑动
Then 主预览切换到对应版本，并更新采用与下载目标。

### R4 采用与下载

**Requirement**：用户可以在审片层完成采用和下载。

**Scenario R4.1**
Given 当前预览版本尚未采用
When 用户点击“采用此版”
Then 调用既有采用接口，组内选中状态同步更新并刷新生成状态。

**Scenario R4.2**
Given 当前预览版本已经采用
Then 采用按钮禁用并明确显示“当前采用”。

**Scenario R4.3**
Given 用户点击下载
Then 下载当前预览版本，文件名继续使用关键帧导出规则。

## 5. 交互与验收

- 审片入口卡片与全屏层按钮触控目标不小于 44px。
- 全屏层支持关闭按钮与 Escape，并避让上下安全区。
- 版本轨道使用横向滚动与 scroll snap，不造成页面横向溢出。
- 图片有可读 `alt`，当前版本不能只靠颜色区分。
- 支持 `prefers-reduced-motion`。
- 分组逻辑有单元测试；App 接线、接口复用、下载与无障碍有回归测试。
- 全量测试、类型检查和生产构建通过。
