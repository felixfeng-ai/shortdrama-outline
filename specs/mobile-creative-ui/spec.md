# App 创作 Agent 下一批 UI

## 目标

保持轻量 Agent 首页和暖白创作现场，不把 Web 工作台搬进 App。本轮补齐推荐式生成、批次任务、审片协作、Agent 记忆和首次演示。

## 能力点

### R1 推荐式生成

- 生成页先显示当前推荐目标，不再默认铺开全部目标列表。
- 用户可通过“更换目标”打开原生底部选择层。
- 推荐优先选择已具备首帧、没有进行中任务的目标。
- 视频费用、模型、时长和阻断原因保持在主操作附近。

### R2 批次任务与待审

- 同一 `batchId` 的任务折叠为一张批次卡。
- 批次卡显示进度、预算和失败数量，可展开查看单镜。
- 已成功且有资产的视频任务标记为“可审片”。

### R3 审片协作

- 视频审片页支持 A/B 对比当前版本和其他版本。
- 用户可写退回原因，评论锚定到当前镜头，不改变采用版本。
- 可读取该镜头的开放批注并标记已处理。

### R4 Agent 记忆层

- Mobile Context 返回锁定角色/地点、已采纳判断、最近否决方向、开放批注。
- Agent 首页提供可展开的“它记住了什么”，不扩成管理面板。
- 展开层说明本轮会读取哪些项目内容。

### R5 五分钟演示

- 首次演示从示例项目开始，按真实链路引导。
- 每一步只跳转真实页面，不自动调用模型、不伪造生成结果。
- 完成状态在 Web/Native 本地持久化。

## 验收

- 每个能力点有先失败后通过的单元测试或 UI 接线测试。
- 390 和 375 宽度无横向溢出，首页层级保持原设计。
- App/Web 全量测试、类型检查、Expo export、Next build 通过。
