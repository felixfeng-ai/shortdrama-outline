# 原生 App · 项目新建、切换与导入

## 1. 目标

让 App 成为可独立管理项目入口的客户端：创建项目、切换当前项目、导入 Web 导出的项目包。项目仍写入同一套 `projects` / `snapshots`，不新增 App 专属数据。

## 2. 硬边界

- 新建项目调用 `/api/projects`。
- 导入调用 `/api/project-import`，只接受项目包 ZIP。
- 项目选择只保存项目 ID，不复制项目内容。
- 当前项目会影响 `/api/mobile/context`、Agent 和写回目标。
- 未登录时沿用匿名会话；登录后沿用同一 `user_id`。
- 导入失败必须清理服务端半成品项目，不显示成功。

## 3. 能力与场景

### R1 新建

Given 用户输入 1–100 字项目名
When 点击新建
Then App 创建项目、选中新项目并返回 Agent 首页。

### R2 切换

Given 用户有多个项目
When 点击某个项目
Then 当前项目 ID 持久化，App 重新读取该项目的集/场、镜头和 Agent 上下文。

### R3 导入

Given 用户选择成剧导出的 ZIP 项目包
When 导入成功
Then App 选中导入项目并显示快照、任务、关键帧与原文恢复警告。

### R4 选择容错

Given 当前项目已被 Web 删除
When App 刷新
Then App 清除失效选择并回退到最近项目，不持续报错。

### R5 同步

Given 新建或导入成功
Then 项目立即出现在 Web 的项目列表，Web 刷新可打开。

## 4. 验证

- 项目创建、示例载入、项目包导入 API 测试通过。
- 项目选择查询参数与失效回退测试通过。
- ZIP manifest 与关键帧 FormData 组装测试通过。
- App 与 Web 使用临时数据库验证创建后能看到同一个项目。
- 390/375 验证新建弹层、项目列表、导入中、成功和失败状态。

## 5. 当前验收

- 隔离数据库实测：App 创建项目后，Web `/api/projects` 立即能看到同一项目。
- 新建项目 C 后自动选中；切回项目 A 后 `chengju.activeProject.v1` 更新，刷新 App 仍停留在项目 A。
- 项目切换请求已确认发送到 `/api/mobile/context?projectId=...`。
- 成剧导出的 ZIP 项目包在 App 中成功导入，恢复 8 个快照并显示 1 条警告。
- 无效 ZIP 返回“不是有效的 ZIP 文件”，没有创建半成品项目。
- 当前选择指向已删除项目时，App 清除失效 ID 并回退到最近项目，不持续显示同步错误。
- 390/375 的项目列表、新建弹层、导入成功和导入失败状态均无横向溢出。
